# Matrix extension

This reading constructs the smooth frame change that extends an invertible matrix from a bounded open set outside an arbitrary compact subset to the whole exterior, with degree-zero behavior at infinity. The complete proof retains ordered transport, inverse series, curvature, smooth parameters and every exterior derivative bound. It includes an explicit Peano–Baker computation, solved exercises and the global map relating any two choices of factors.

Read [the lesson](matrix-extension.html), [the 13-page PDF](pdf/matrix-extension.pdf), [the editable TeX](tex/matrix-extension.tex), or [the Markdown source](src/matrix-extension.md). [Two complete foundation readings](supporting-proofs.html) supply finite linear algebra, compactness and calculus. The offline reader/source ZIP includes all three lessons and both map figures.
