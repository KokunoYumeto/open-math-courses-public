# Uniform Dirichlet estimates in the boundary elliptic region

Read [the proof](uniform-dirichlet-estimates-in-the-boundary-elliptic-region.html) or edit [its source](uniform-dirichlet-estimates-in-the-boundary-elliptic-region.md). A uniform coercive Dirichlet estimate handles strictly negative tangential principal forms, including the compressed boundary equator. A complete weak commutator and finite full-derivative iteration retain all actual source terms. One fixed scalar source test controls the full targets with the original Banach norm.

The prerequisite proof index gives the exact earlier results used in the arguments. Some prerequisite proofs are external readings linked by that index.
