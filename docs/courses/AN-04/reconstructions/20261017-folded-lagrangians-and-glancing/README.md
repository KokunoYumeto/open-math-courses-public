# Folded Lagrangians and glancing pairs

Read [the companion](folded-lagrangians-and-glancing-pairs.html) or edit [its source](folded-lagrangians-and-glancing-pairs.md). The proofs give the complete folded Lagrangian normal form, the intrinsic potential data, and the full ordinary glancing-pair theorem through characteristic quotients and a relative form correction preserving both hypersurfaces. The earlier homogeneous theorem supplies the conic pair with its exact marked coordinates and full Hamiltonian extension equations.

The prerequisite proof index gives the earlier results used here. Reproducible sources are check_models.py and figures/draw_folded_lagrangian.py.
