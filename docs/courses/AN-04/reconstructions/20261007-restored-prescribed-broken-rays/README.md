# Constructing a singular reflected ray

Read [the lesson](prescribed-broken-rays-preparation.html) or edit [its source](prescribed-broken-rays-preparation.md). It constructs a distribution singular exactly along a prescribed finite transverse reflected ray, with zero Dirichlet trace and forcing singular exactly at its two interior endpoints. The proof retains arbitrary smooth complex lower terms, caustics and intersecting base projections under the stated injective positive-cosphere hypothesis.

The calculations include the boundary-compatible inverse, canonical endpoint splice and local Sobolev threshold.

The prerequisite proof index gives the exact earlier results used in the arguments.
