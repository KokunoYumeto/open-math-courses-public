# Boundary traces of the incoming field

Read [the complete proof](incoming-field-boundary-traces.html) or edit [the source](incoming-field-boundary-traces.md). A normal Fourier profile estimate proves boundary regularity for ordinary operators of order below minus one half. A full matrix parametrix on the normal elliptic caps then proves regularity of both actual incoming traces at the glancing tangential covector. The normal trace is explicitly identified with the weak Green trace.

The proof map connects 13 entries to 1263 earlier entries in 72 maps, including 92 external Lebl providers.   Run python -B check_models.py; the general analytic estimates are proved in the lesson.

Only the imposed Dirichlet or Neumann datum is identified in its respective boundary problem. The response of complementary boundary frequencies, sharp Airy mapping and full strict propagation are not established by this component.
