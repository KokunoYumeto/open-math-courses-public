# Actual paired normal composition

Read [the companion](paired-normal-composition.html) or edit [its source](paired-normal-composition.md). It proves actual composition with complete normal expansions, both tangentially separated kernel configurations, the improved remainder estimates for both local inverse errors, and finite corrections on their distinct error spaces. Three solved exercises and the original diagram explain the coefficient signs and retained normal diagonal.

The proof map connects eleven new proof sections to 253 exact earlier proofs. The [review](proof-review.json) specifies the scope. Four finite check groups pass; all 245 formulas render. The complete desktop reader, diagram and two mobile samples were inspected, with every mobile formula extent checked.

Run `python -B check_models.py` for the finite checks and `python -B figures/build_figure.py` for the diagram. The complete analytic arguments are in the source; finite tests do not establish the general estimates.

The approved source is Hörmander III, Springer 2007, with the existing AN-03 calculus consulted for its full product requirements.
