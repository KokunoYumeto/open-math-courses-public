# Convex billiards at infinite contact

The [lesson](convex-billiards-at-infinite-contact.html) and [editable source](convex-billiards-at-infinite-contact.md) construct a smooth flat convex obstacle, an exact reflected polygon with finite travel time and a boundary gliding arc through the same full wave characteristic state.

Three complete solutions and an original reproducible diagram accompany the 14-entry proof map, source credit, [proof review](proof-review.json), [reader checks](reader-check.json) and [12 finite exact identities](model-check.json). The map connects to539 earlier entries across27 maps and explicitly records102 external human foundations. Finite identities support the algebra; the smoothness, convergence and existence arguments are written in the lesson.

Both specified curves are proved to be uniform compressed limits of finite transverse broken rays. The example demonstrates nonuniqueness at infinite contact. It makes no universal assertion about transverse approximation of nonunique arcs. Original expression and figure sources are CC0-1.0; linked components retain their terms.
