# Trapped characteristics and the escape criterion

The [lesson](trapped-characteristics-and-the-escape-criterion.html) proves the complete trapping/escape criterion with stationary singleton obstructions explicit. It retains the oriented tangent in the limiting-curve argument and constructs actual real-flow corridors and a smooth admissible band for rank-two access. Together with the gain and existence proofs linked below, these results give Theorems 26.11.1–3 and Definition 26.11.4.

The prerequisite proof index gives the exact earlier results used in the arguments. Some prerequisite proofs are external readings linked by that index.

[Escape regularity and semi-global solutions](../20261015-escape-regularity-and-solvability/escape-arcs-regularity-and-semiglobal-solutions.html) and [strict-loss solvability](../20261015-strict-loss-solvability/strict-sobolev-loss-and-compact-solvability.html) give the analytic consequences. The global principal-type definition requires escape over every compact set.
