# Normal inverse expansions

Read [the companion](normal-inverse-expansions.html) or edit [its source](normal-inverse-expansions.md). It proves actual differentiated inverse estimates on both normal-frequency tails, the full separated-kernel estimates, and the ordered formal algebra with both inverse recursions and finite errors. Three solved exercises and the diagram distinguish matrix inversion from operator inversion.

The proof map binds nine new proof sections to 239 exact earlier nodes. The [review](proof-review.json) gives the scope. Four finite check groups pass; all 232 formulas render. The complete desktop reader, diagram and two mobile samples have been inspected, with all mobile formula extents checked.

Run `python -B check_models.py` for the finite algebra checks and `python -B figures/build_figure.py` for the diagram. The general mathematical proofs are in the source.
