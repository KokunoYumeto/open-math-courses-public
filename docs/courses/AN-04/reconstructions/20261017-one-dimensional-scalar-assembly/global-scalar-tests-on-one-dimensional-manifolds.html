Global scalar tests on one-dimensional manifolds

Boundary collars have no tangential coordinate in dimension one. Their full residual kernels nevertheless need not be ordinary smoothing kernels. We combine the existing scalar Fourier tests in the collars with one positive interior test, retaining every residual term. The resulting norm inequality has the coarse Banach term required for forcing and observation tests in a propagation estimate.

Independent exposition, proofs, examples and illustration: CC0-1.0. The approved antecedent is Lars Hörmander, The Analysis of Linear Partial Differential Operators III, Springer 2007 eBook, ISBN 978-3-540-49938-1, §§18.3 and24.7. The scalar Fourier construction supplies the complete half-line factors in every dimension. The global kernel calculus supplies their coordinate and support conventions. External human foundation proofs remain explicit in the proof map; internal closure of a CC0-only export is not claimed.

2. Which kernel errors have a coarse bound?

K0. Smooth kernels flat in the input. Suppose a family RaR_aRa​ has compact projections and smooth kernels on the original product X×XX\times XX×X, flat to every order at the input boundary, with all these seminorms uniformly bounded. Then

∥RaDau∥2≤C∥u∥B.(OS3) \|R_aD_au\|_2\leq C\|u\|_{\mathcal B}. \tag{OS3} ∥Ra​Da​u∥2​≤C∥u∥B​.(OS3)

Here is the actual dual argument. On the compact input set, continuous embedding in extendible distributions gives a finite flat-test seminorm and a constant bounding the pairing with each uuu in the unit ball of B\mathcal BB; this is the proved flat-test bound NGR:B1–B2. For a fixed output point, transpose DaD_aDa​ onto the input kernel, retaining its complete formal adjoint and the density. Differential operators preserve flatness. Its finite test seminorm is uniformly bounded over the compact output set and parameter family. The pairing is therefore bounded pointwise by C∥u∥BC\|u\|_{\mathcal B}C∥u∥B​. Integrating its square over that finite-density output compact proves (OS3). Kernels supported away from the input boundary are included.

Flatness is essential here. A full residual boundary kernel can have a nonzero smooth coefficient at the new front face and is not silently put into this class.
