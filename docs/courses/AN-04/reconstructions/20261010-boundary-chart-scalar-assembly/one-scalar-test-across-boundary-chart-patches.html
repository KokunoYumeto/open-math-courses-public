One scalar test across boundary-chart patches

The local source estimates retain a finite collection of full boundary operators. A single scalar test must control that entire collection, including the residual kernels. This lesson constructs such a test for arbitrary compact microlocal patches in a positive-dimensional boundary chart. Its key step is an exact orthogonal placement of the residual output.

The admitted antecedent is Lars Hörmander, The Analysis of Linear Partial Differential Operators III, corrected edition reprinted in 2007, §§18.3 and 24.7, especially the two observation estimates on printed pages 465–467. The complete argument below uses the programme's global boundary calculus, uniform microsupport proof, fixed elliptic and residual reduction, and exact scalar residual factorization. It supplies a missing assembly step; it does not replace the remaining propagation proofs by a citation.
