# Half-space operators and complete boundary sources

Read the companion or edit its source. It proves both the truncated volume map and the all-order boundary-supported layer map, with the full jet Gram norm, every original coefficient derivative and the exact gains of both finite inverse errors.

The proof map connects sixteen new proofs to 311 exact earlier proofs. The [review](proof-review.json) records the scope. Four whole exercises and a reproducible support diagram accompany the argument. All four finite check groups pass; 287 formulas and 30 numbered displays render. The complete desktop reader, diagram and two mobile samples were inspected, and every mobile display extent was checked.

Run `python -B check_models.py` for the finite algebra checks and `python -B figures/build_figure.py` to reproduce the diagram. The general analytic theorems are proved in the source.

This original exposition is CC0; linked earlier components retain their own terms. The approved Hörmander III and the existing AN-03 source are credited in the source and proof map. Complete trace symbols, the stable projection, elliptic boundary regularity and final U051 integration remain unfinished. The repository stays private and the full AN-04 goal remains active.
