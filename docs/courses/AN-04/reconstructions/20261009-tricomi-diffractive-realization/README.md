# Singularities on a diffractive Tricomi ray

Read [the proof](singularities-on-diffractive-tricomi-rays.html) or edit [its source](singularities-on-diffractive-tricomi-rays.md). At a strict diffractive state outside the closure of the elliptic boundary set, the construction gives a continuous distribution with zero boundary value, smooth forcing on a base neighborhood and exactly the two-leg singular ray. It retains arbitrary complex lower terms, actual Cauchy jets, the finite Hamilton-time endpoint proof and every local-symbol discrepancy.

The explicit normalized Airy series supplies a convergent Fourier solution with the actual Cauchy jets. A local interior construction also treats nearby elliptic turns with vertical base tangents, giving the strict-diffractive realization in the complementary elliptic-closure case.
