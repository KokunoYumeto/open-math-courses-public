# Recovering the normal graph from a Banach bound

Read [the proof](normal-graphs-from-banach-bounds.html) or edit [its source](normal-graphs-from-banach-bounds.md). A Banach-controlled weak distribution order and one negative tangential source norm give a uniform bound for the actual solution, its first two normal derivatives and both rough traces. The proof covers smooth compact families of noncharacteristic matrix operators and proves trace convergence on the actual graph, including changing coefficients.

The full local source norm is an explicit hypothesis. Its conversion from admissible tests is given by [global scalar assembly](../20261017-angular-output-reserve-assembly/scalar-tests-from-a-missing-tangential-direction.html). Full ordinary normal smoothness of the source is not an extra prerequisite for that L2 estimate.
