# Interior recovery of the two Airy coefficients

Read [the lesson](interior-airy-coefficient-recovery.html) or edit [its source](interior-airy-coefficient-recovery.md). A positive matrix normal operator gives fixed bounded extraction of both interior Airy coefficients and recovers the stable decaying coefficient in H5/6 from energy observations. Exact affine solutions show why a separate boundary estimate is necessary.

The prerequisite proof index gives the exact earlier results used in the arguments. Some prerequisite proofs are external readings linked by that index.
