# Generalized singular rays for the weak wave problem

Read [the proof](generalized-singular-rays-for-the-weak-wave-problem.html) or edit [its source](generalized-singular-rays-for-the-weak-wave-problem.md). For the complete smooth single-face weak wave class, the lesson verifies every hypothesis of the earlier closed-set trajectory theorem. It constructs maximal singular generalized rays, proves escape from compact source-free sets and derives the finite-contact uniqueness consequence. Both actual weak domains and all complex matrix lower terms are retained. At infinite contact the theorem asserts existence of a singular continuation.
