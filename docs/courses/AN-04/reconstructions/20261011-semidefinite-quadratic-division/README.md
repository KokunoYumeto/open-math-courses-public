# Semidefinite division with a nonnegative quotient

Read [the lesson](semidefinite-division-with-a-nonnegative-quotient.html) or edit [its source](semidefinite-division-with-a-nonnegative-quotient.md). The negative part of the preliminary quotient vanishes to every order at the constrained closed set. An explicitly constructed smooth majorant corrects it without changing the exact quotient there. Both semidefinite signs, a common compact-time neighborhood and homogeneous extension are included.
