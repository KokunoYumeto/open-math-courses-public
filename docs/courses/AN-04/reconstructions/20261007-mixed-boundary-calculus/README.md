# Mixed boundary calculus

Read [the companion](mixed-boundary-calculus.html) or edit [its source](mixed-boundary-calculus.md). It proves mixed-symbol inversion, exact composition, the two different error gains and boundedness on every real two-weight Sobolev space. Four solved exercises and an exact frequency-metric diagram explain the hypotheses and signs.

The prerequisite proof index gives the exact earlier results used in the arguments.
