# Global observation with full source and observation tests

Read [the proof](global-observation-with-full-source-and-observation-tests.html) or edit [its source](global-observation-with-full-source-and-observation-tests.md). On arbitrary manifolds with noncharacteristic boundary, finitely many fixed full source and observation tests give the uniform observation estimate with one geometric parameter range before all target orders. Parameter coordinate changes, cross-chart kernels, all residuals and the original Banach remainder remain in the proof. The actual tested graph completion is included.

The single-source, single-observation form follows for noncompact boundaries, one-dimensional manifolds, without boundary, and for separately suitable compact-channel assemblies. Three complete solutions include a periodic spatial cylinder, a compact reflected-wave cylinder and a graph-density obstruction. The prerequisite proof index gives the earlier results used here. Run `python -B model_check.py` and `python -B figures/build_figure.py` for the supporting algebra and diagram.

This component proves the global finite-test analytic estimate and its actual tested graph. The separate [general scalar family and observation estimates](../20261017-angular-output-reserve-assembly/scalar-tests-from-a-missing-tangential-direction.html) supplies one full scalar source test and one observation test on arbitrary manifolds.
