Read [the proof](scalar-tests-when-the-whole-boundary-cosphere-is-allowed.html) or edit [its source](scalar-tests-when-the-whole-boundary-cosphere-is-allowed.md). A compact boundary admits one fixed scalar test for complete finite-order families when the allowed cone contains its entire cosphere. A direct coercive differential operator controls all required logarithmic-cylinder derivatives and every full kernel tail. Checked interior gluing then recovers the whole collar norm from the scalar sum, retaining the original Banach remainder.
