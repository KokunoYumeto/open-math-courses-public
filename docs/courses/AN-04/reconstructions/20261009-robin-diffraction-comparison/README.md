# Robin diffraction by Dirichlet comparison

Read [the proof](robin-diffraction-by-dirichlet-comparison.html) or edit [its source](robin-diffraction-by-dirichlet-comparison.md). The lesson extends the fixed-region Dirichlet estimate to finite negative Sobolev order. Subtracting the actual value-trace Airy parametrix then gives a regular Dirichlet difference. Its actual conormal trace and the full Robin inverse make the original value trace regular. The proof returns to the natural-dual weak problem and establishes strict diffractive singular segments for both original boundary domains.
