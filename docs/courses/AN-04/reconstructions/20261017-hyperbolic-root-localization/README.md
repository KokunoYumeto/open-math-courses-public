# Hyperbolic roots and quadratic localization

The [reader](hyperbolic-roots-stability-and-quadratic-localization.html) and [editable source](hyperbolic-roots-stability-and-quadratic-localization.md) develop the robust constant-coefficient Cauchy criterion, exact root-splitting obstructions, real polynomial clusters, genuine-characteristic Hessians and their convex quadratic cones. The full-neighborhood and one-sided cases have explicit hypotheses. Four solved exercises include a periodic smooth datum with no distributional solution.
