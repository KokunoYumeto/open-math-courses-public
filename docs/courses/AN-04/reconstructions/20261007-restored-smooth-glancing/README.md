# Smooth glancing regularity in parabolic windows

Read [the complete lesson](smooth-glancing-neighborhoods-and-windows.html) or edit [its source](smooth-glancing-neighborhoods-and-windows.md). It proves noncharacteristic energy regularity and iterates the glancing estimate on one common neighborhood, for the full smooth-face time-variable scalar wave form and both weak domains. Both signed clocks and a uniform quadratic-window argument retain every complex lower term.

The guard uses an actual quadratic-form remainder. The finite partition, two-point coordinate bound and Sobolev jump calculation are explicit.

The prerequisite proof index gives the exact earlier results used in the arguments.
