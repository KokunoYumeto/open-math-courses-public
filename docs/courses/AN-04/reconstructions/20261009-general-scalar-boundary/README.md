# Scalar boundary propagation through general glancing

Read [the proof](scalar-boundary-propagation-through-general-glancing.html) or edit [its source](scalar-boundary-propagation-through-general-glancing.md). For a general scalar real quadratic principal symbol and a noncharacteristic smooth face, the lesson proves the glancing window estimate, bootstraps all orders on one fixed region and assembles the full distributional Dirichlet propagation theorem. Complex lower coefficients, indefinite or degenerate tangential forms, radial states and infinite contact are included. Singular arcs continue through finite compact endpoints away from the stated exceptional states.

The proof map connects 16 entries to 1879 earlier entries in 96 maps, including 92 external Lebl providers.   Run python -B check_models.py for the model identities; the analytic proof is in the lesson.

 The general scalar theorem here uses Dirichlet data; the earlier weak-wave theorem retains its own Robin conclusion. Original expression is CC0-1.0; linked components retain their terms.
