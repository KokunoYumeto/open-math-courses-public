# From parabolic wavefront windows to generalized singular rays

Read [the lesson](parabolic-wavefront-windows-and-rays.html) or edit [its source](parabolic-wavefront-windows-and-rays.md). It proves how a uniform two-sided quadratic regularity window supplies the exact gliding tangency condition and, with the complete earlier geometric theorem, a maximally continued generalized arc. The analytic regularity criterion remains an explicit hypothesis.

The reduced-cosphere transfer specifies its projection, conic-set condition and normalized field. A linear-window counterexample explains the quadratic scale.

The prerequisite proof index gives the exact earlier results used in the arguments.
