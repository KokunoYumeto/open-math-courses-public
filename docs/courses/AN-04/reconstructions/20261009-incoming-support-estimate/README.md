# Incoming root estimates on the full diffraction support

Read [the complete proof](incoming-root-estimates-on-the-full-support.html) or edit [the source](incoming-root-estimates-on-the-full-support.md). A regular incoming germ and the stated fixed-neighborhood source condition imply the required estimate on the whole hyperbolic incoming support. The proof constructs the full matrix root, retains the matrix commutator in cutoff transport, and identifies the actual weak trace before recovering its smoothness.
