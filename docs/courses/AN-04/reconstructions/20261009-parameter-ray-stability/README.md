# Stable observation regions for boundary rays

Read [the proof](stable-observation-for-boundary-rays.html) or edit [its source](stable-observation-for-boundary-rays.md). If every maximal limiting boundary ray meeting the target meets the observation region, compact target sets retain that access under small smooth changes of the operator. The proof gives a uniform normalized travel-time bound, including arbitrarily many reflections, higher contact and stationary rays.
