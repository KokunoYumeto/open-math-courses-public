# A global symplectic parametrix with Hermitian projectors

Read [the lesson](global-symplectic-parametrix-and-hermitian-projectors.html) or edit [its source](global-symplectic-parametrix-and-hermitian-projectors.md). A proper partition assembles the local inverses on a general manifold. A proved half-order commutator estimate gives the regularity and microlocality of a positive inverse, allowing Hermitian normalization of the kernel and cokernel projectors. The lesson proves both inverse identities, exact wavefront, every-real Sobolev mapping and uniqueness in the stated pseudolocal class.
