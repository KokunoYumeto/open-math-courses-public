# Sharp Sobolev mapping for the decaying Airy kernel

Read [the lesson](sharp-sobolev-mapping-for-the-decaying-airy-kernel.html) or edit [its source](sharp-sobolev-mapping-for-the-decaying-airy-kernel.md). The variable-coefficient decaying Airy kernel gains one sixth of a Sobolev derivative. A positive normal symbol proves the reverse microlocal estimate and sharpness, including the H5/6 coefficient threshold for H1 energy.
