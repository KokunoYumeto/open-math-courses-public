Sharp Sobolev mapping for the decaying Airy kernel

The real Airy integral resolves a caustic by adding one frequency variable. For a boundary input and a full interior collar, that variable produces a smooth canonical relation: the output projection is an immersion and the input projection has one-dimensional fibers. Composing the adjoint with the operator therefore gives an ordinary pseudodifferential operator. We prove the resulting gain of one sixth of a derivative, including the sharp energy exponent 5/65/65/6, for the variable-coefficient phase and matrix amplitudes already constructed in this course.

The primary antecedent is Melrose–Taylor, Boundary Problems for Wave Equations With Grazing and Gliding Rays, §6.3, especially (6.3.28). The argument here uses the complete programme proofs of the boundary cubic phase, matrix amplitudes, Airy contour and tails, clean composition and Sobolev localization. It keeps the extra dimension in the order calculation.
