The sharp lower bound for a finite system

The boundary energy argument uses a positive 2×22\times22×2 matrix symbol. This companion proves its full sharp lower bound by applying the already proved scalar moving probe to each component. The result holds for every fixed finite matrix size NNN. Constants may depend on NNN; no dimension-independent or infinite-dimensional assertion is made.
