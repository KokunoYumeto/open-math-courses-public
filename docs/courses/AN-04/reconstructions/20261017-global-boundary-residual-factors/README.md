# Global scalar factors for boundary residuals

Read [the proof](global-scalar-factors-for-boundary-residuals.html) or edit [its source](global-scalar-factors-for-boundary-residuals.md). One scalar full boundary residual test controls a bounded finite list of complete residual families on a compact smooth boundary, including kernels between different charts and boundary components. The estimate retains the original Banach remainder. Its tangential smoothing square root and normal kernel bounds are proved explicitly.

The prerequisite proof index gives the earlier results used here. Run `python -B model_check.py` and `python -B figures/build_figure.py` for the supporting algebra and diagram. The full analytic proof is in the lesson.

This theorem concerns complete residual families. General finite-order tests and the observation estimate are treated in the separate [general scalar family and observation estimates](../20261017-angular-output-reserve-assembly/scalar-tests-from-a-missing-tangential-direction.html).
