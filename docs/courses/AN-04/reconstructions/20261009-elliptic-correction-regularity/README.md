# Elliptic corrections in the original boundary energy norm

Read [the complete proof](elliptic-corrections-in-the-original-energy-norm.html) or edit [the source](elliptic-corrections-in-the-original-energy-norm.md). A full interior kernel estimate proves compressed regularity of ordinary elliptic corrections in the original H1 energy norm. Subtracting the actual normal-cap correction from LG:L7 therefore preserves the compressed energy wave-front set on a fixed neighborhood.

The prerequisite proof index gives the exact earlier results used in the arguments. Some prerequisite proofs are external readings linked by that index.
