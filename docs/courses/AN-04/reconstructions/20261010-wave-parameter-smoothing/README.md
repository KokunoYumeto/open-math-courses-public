# Wave smoothing uniform in the coefficients

Read [the proof](wave-smoothing-uniform-in-the-coefficients.html) or edit [its source](wave-smoothing-uniform-in-the-coefficients.md). A family of mixed Dirichlet waves has uniformly bounded derivatives deep inside the forward cone. The proof keeps full observation inputs inside the common zero region, normalizes before parameter differentiation, retains the complete tangential source system, recovers every ordinary boundary derivative and uses one fixed parameter neighborhood.

The prerequisite proof index gives the exact earlier results used in the arguments. Some prerequisite proofs are external readings linked by that index.

The exact strict covector criterion identifies every flat reflected and tangent direction returning from a forward cone. The open observation cone keeps both characteristic root representatives and restricts all observations to the common zero region.
