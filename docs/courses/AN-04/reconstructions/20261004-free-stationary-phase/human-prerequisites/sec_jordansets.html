L10.5.1: Jordan measurability iff null boundary, using an interior containing rectangle.

L10.5.5: Every bounded continuous function on a bounded Jordan set is Riemann integrable; full proof.

Proposition 10.5.5.

If S⊂RnS \subset \R^nS⊂Rn is a bounded Jordan measurable set and f ⁣:S→Rf \colon S \to \Rf:S→R is a bounded continuous function, then fff is integrable on S.S\text{.}S.

Define the function f~\widetilde{f}f​ as above for some closed rectangle RRR with S⊂R.S \subset R\text{.}S⊂R. If x∈R∖S‾,x \in R \setminus \widebar{S}\text{,}x∈R∖S, then f~\widetilde{f}f​ is identically zero in a neighborhood of x.x\text{.}x. Similarly, if xxx is in the interior of S,S\text{,}S, then f~=f\widetilde{f} = ff​=f on a neighborhood of xxx and fff is continuous at x.x\text{.}x. Therefore, f~\widetilde{f}f​ is only ever possibly discontinuous at ∂S,\partial S\text{,}∂S, which is a set of measure zero, and we are finished.
