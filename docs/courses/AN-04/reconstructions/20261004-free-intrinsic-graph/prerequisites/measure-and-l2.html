M1. The generating-class lemma

The following is the independent argument from AN03-P004, Section 16.2. A Dynkin class on a set ZZZ contains ZZZ, is closed under relative complements, and is closed under countable disjoint unions. It is closed under differences of nested members: if A⊂BA\subset BA⊂B belong, complement the disjoint union A∪(Z∖B)A\cup(Z\setminus B)A∪(Z∖B).
