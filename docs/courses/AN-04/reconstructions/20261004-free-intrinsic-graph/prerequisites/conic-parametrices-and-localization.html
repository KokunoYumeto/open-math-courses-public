Conic inverses and the full localization theorem

An elliptic test can be inverted near its noncharacteristic directions. The inverse need not be an actual inverse on all distributions: a smooth error is enough. We construct that inverse with every symbol remainder, then prove that finitely many directional tests recover the full local Besov estimate. This supplies the converse in the intrinsic localization theorem, including finite-rank matrix tests.

This is a bounded modified selection of AN03-U010, Section 2, and AN03-U012, Section 6, with the conic and intrinsic arguments completed below.
