# Boundary inverses with a retained projection defect

Read [the companion](weighted-boundary-inverse.html) or edit [its source](weighted-boundary-inverse.md). It constructs the actual weighted boundary inverse under the proved order-one Cauchy projection defect, preserving all original boundary orders, both rectangular inverse constructions, complete asymptotic remainders and exact reconstruction errors.

The proof map connects 16 new proofs to 475 exact earlier proofs. The [review](proof-review.json) records the scope. Four full calculations and a reproducible figure accompany the proofs. All four finite check groups pass; 223 formulas and 27 numbered displays render. All ten desktop captures, the figure and two mobile samples were inspected; all mobile display extents were measured.

Run `python -B check_models.py` for the finite checks and `python -B figures/build_figure.py` to reproduce the figure. The full general proofs remain in the source.
