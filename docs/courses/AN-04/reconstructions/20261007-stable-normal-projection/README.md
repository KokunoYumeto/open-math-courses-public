# Stable normal modes and the residue projection

Read the companion or edit its source. It constructs the stable Cauchy space of the whole original matrix polynomial and proves that its projection is the complete one-sided residue matrix, retaining the leading coefficient, repeated roots, every jet weight and the full jump source.

The proof map connects eighteen new proofs to 323 exact earlier proofs. The [review](proof-review.json) records the scope. Four whole calculations and a reproducible figure accompany the argument. All four finite check groups pass; 243 formulas and 30 numbered displays render. The complete desktop reader, figure and two mobile samples were inspected, and every mobile display extent was checked.

Run `python -B check_models.py` for the finite checks and `python -B figures/build_figure.py` to reproduce the figure. The general proofs are in the source.

This original exposition is CC0; linked earlier components retain their own terms. The approved Hörmander III and the existing AN-03 sources are credited in the source and proof map. Comparison with the variable-coefficient inverse, the weighted boundary inverse, elliptic boundary regularity and final U051 integration remain unfinished. The repository stays private and the full AN-04 goal remains active.
