# Stable normal modes and the residue projection

Read [the companion](stable-normal-projection.html) or edit [its source](stable-normal-projection.md). It constructs the stable Cauchy space of the whole original matrix polynomial and proves that its projection is the complete one-sided residue matrix, retaining the leading coefficient, repeated roots, every jet weight and the full jump source.

The prerequisite proof index gives the exact earlier results used in the arguments.
