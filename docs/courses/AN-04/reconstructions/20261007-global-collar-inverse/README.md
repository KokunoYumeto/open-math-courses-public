# Global collar inverses

Read [the companion](global-collar-inverse.html) or edit [its source](global-collar-inverse.md). It constructs an actual global inverse to every prescribed finite error order for the original elliptic collar polynomial. Complete tangential coefficients, bundle maps, densities, separated kernels and both error spaces are retained. It also proves every real two-weight cylinder map and the exact localized return to the original collar. The chart norm comparison includes the entire output tail of the weight operator.

The proof map connects twelve new proof sections to 284 exact earlier proofs. The [review](proof-review.json) records the full scope. Four solved exercises and an original support diagram accompany the argument. Four finite check groups pass, all 332 formulas render, and the complete desktop reader, diagram and two mobile samples were inspected. Every mobile formula extent was checked.

Run `python -B check_models.py` for the finite checks and `python -B figures/build_figure.py` for the reproducible diagram. General analytic estimates are proved in the source, not inferred from those finite tests.

This original exposition is CC0; linked earlier components retain their own terms. The approved source is Hörmander III, Springer 2007; the existing AN-03 collar calculus was consulted.  Half-space maps, full boundary source jets, one-sided traces and U051 integration remain unfinished.
