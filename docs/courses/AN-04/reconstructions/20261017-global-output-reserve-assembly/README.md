# One scalar test with a global boundary output reserve

Read [the proof](one-scalar-test-with-a-global-boundary-output-reserve.html) or edit [its source](one-scalar-test-with-a-global-boundary-output-reserve.md). Complete scalar finite-order families admit one fixed scalar tester with the prescribed compact conic microsupport when a boundary point lies outside the common compact base projection. This includes every positive-dimensional noncompact boundary. An explicit flat-cell L2 encoding places the full residual output in an unused boundary patch; its disjointness from the complete elliptic output gives the exact norm identity. The original Banach remainder is retained.

The prerequisite proof index gives the earlier results used here. Run `python -B model_check.py` and `python -B figures/build_figure.py` for the supporting algebra and diagram. The full analytic proof is in the lesson.

This component uses an unused boundary base point. For compact boundaries with complete relevant base coverage, see [whole-manifold tangential-equator construction](../20261017-global-tangential-equator-assembly/one-scalar-test-when-all-boundary-tangential-directions-are-allowed.html) and [general scalar family and observation estimates](../20261017-angular-output-reserve-assembly/scalar-tests-from-a-missing-tangential-direction.html).
