# Weighted energy bounds for the growing Airy kernel

Read [the lesson](weighted-energy-bounds-for-the-growing-airy-kernel.html) or edit [its source](weighted-energy-bounds-for-the-growing-airy-kernel.md). An explicit exponential coefficient weight bounds the variable-coefficient growing Airy kernel in H1. Combined with the decaying-kernel estimate, this constructs the two-mode parametrix in the actual energy space, with a smooth local equation error and the correct weak value and conormal traces.

The prerequisite proof index gives the exact earlier results used in the arguments. Some prerequisite proofs are external readings linked by that index.
