# Glancing with fixed source and observation tests

Read [the proof](glancing-with-fixed-source-and-observation-tests.html) or edit [its source](glancing-with-fixed-source-and-observation-tests.md). On the stated whole-input source patch with a common incoming window, nonradial glancing is controlled by the original Banach norm, one fixed scalar test of the equation and one fixed scalar observation. The scalar normal gauge, finite half-order iteration, full cutoff errors and all residual source families are retained.

The prerequisite proof index gives the exact earlier results used in the arguments. Some prerequisite proofs are external readings linked by that index.
