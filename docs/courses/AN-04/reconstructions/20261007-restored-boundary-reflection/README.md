# Boundary reflection and compressed wavefronts

Read [the lesson](boundary-reflection-preparation.html) or edit [its source](boundary-reflection-preparation.md). The proof follows a wave through a transverse boundary encounter: normal coordinates, two complete ordered factors, smooth Cauchy comparison and recovery of the reflected wave. It permits arbitrary smooth complex lower terms.

The canonical pairing, Riccati cancellation and uniform compressed tester estimates are included.

The prerequisite proof index gives the exact earlier results used in the arguments.
