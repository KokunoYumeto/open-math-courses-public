# Zero-free Airy quotients and matrix Robin matching

Read [the complete proof](zero-free-airy-quotients-and-robin-matching.html) or edit [its source](zero-free-airy-quotients-and-robin-matching.md). It constructs an outgoing Airy mode, proves that its value and derivative have no real zeros, establishes all differentiated quotient bounds, and solves the affine matrix Robin boundary matching problem with a sharp two-thirds gain for the boundary source.

The two-thirds gain concerns the stated affine model.
