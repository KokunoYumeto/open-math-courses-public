# Fixed source tests by packing residual outputs

Read [the proof](fixed-source-tests-by-residual-packing.html) or edit [its source](fixed-source-tests-by-residual-packing.md). Smooth parameter Fourier coefficients are placed in disjoint shrinking tangential output regions. The complete kernel remains residual, including every jet at the accumulation point, and orthogonality gives one fixed residual test controlling the whole family. A fixed elliptic parametrix then gives two fixed source tests for the earlier H2 regularized boundary graph.

The construction requires at least one tangential coordinate. Both fixed tests are explicit. [Global scalar assembly](../20261017-angular-output-reserve-assembly/scalar-tests-from-a-missing-tangential-direction.html) treats the single-test reduction.
