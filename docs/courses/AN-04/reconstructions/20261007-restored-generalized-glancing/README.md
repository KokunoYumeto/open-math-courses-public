# Tangency, gliding and generalized characteristic motion

Read [the lesson](generalized-glancing-flow-preparation.html) or edit [its source](generalized-glancing-flow-preparation.md). It proves the boundary-preserving smooth normal form, contact geometry, generalized-arc compactness and existence, finite-contact uniqueness and a closed-set trajectory theorem. A full homogeneous flat-pulse example proves nonuniqueness at infinite contact.

The proofs include open-domain measure transfer. A diagram displays normal compression and its Liouville density.

The prerequisite proof index gives the exact earlier results used in the arguments.
