# Boundary regularization with admissible source tests

Read [the proof](boundary-regularization-with-source-tests.html) or edit [its source](boundary-regularization-with-source-tests.md). Exact normal-ratio kernel identities construct finitely many source tests in the prescribed compressed cone. They bound an ordinary H2 regularization, its equation and both traces, uniformly over bounded operator and smooth coefficient families. Every residual source term is retained.

The finite source tests can depend on the coefficient parameter. [Global scalar assembly](../20261017-angular-output-reserve-assembly/scalar-tests-from-a-missing-tangential-direction.html) reduces these families to fixed admissible tests under the stated support hypotheses.
