# Corank estimates without radial restrictions

Read [the lesson](corank-estimates-without-radial-restrictions.html) or edit [its source](corank-estimates-without-radial-restrictions.md). Ordinary affine symplectic coordinates, exact unitary changes, uniform annular estimates and Fourier recombination prove the sufficient quarter-corank bound without radial exclusions. A packet argument applied to one fixed operator proves the universal necessary twelfth-corank bound, including a zero-dimensional shared block.

The prerequisite proof index gives the earlier results used here. The two different inequalities do not assert a universal continuity theorem in the gap between them.
