# Stationary phase and symbols with derivative loss

Read [the lesson](stationary-phase-and-symbols-with-derivative-loss.html) or edit [its source](stationary-phase-and-symbols-with-derivative-loss.md). It proves the exact general-rho stationary remainder in every symbol derivative, clean reduction, phase invariance, the Lagrangian class and its invariant principal-symbol quotient. The drop is 2rho-1 and the density degree is m+n/4; the normalization comparison on page16 of Hörmander IV is stated explicitly.

The prerequisite proof index gives the exact earlier results used in the arguments. Some prerequisite proofs are external readings linked by that index.
