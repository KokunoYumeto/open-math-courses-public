# Complete symbols of one-sided boundary traces

Read the companion or edit its source. It proves the complete one-sided trace formula for the actual finite inverse, retaining every source and output derivative, full tangential composition, coordinate pieces and both inverse errors.

The proof map connects fifteen new proofs to 320 exact earlier proofs. The [review](proof-review.json) records the scope. Four whole examples and a reproducible figure accompany the argument. All four finite check groups pass; 209 formulas and 32 numbered displays render. The complete desktop reader, figure and two mobile samples were inspected, and every mobile display extent was checked.

Run `python -B check_models.py` for the finite checks and `python -B figures/build_figure.py` to reproduce the figure. The general analytic theorems are proved in the source.

This original exposition is CC0; linked earlier components retain their own terms. The approved Hörmander III and the existing AN-03 source are credited in the source and proof map. The stable principal projection, weighted boundary inverse, elliptic boundary regularity and final U051 integration remain unfinished. The repository stays private and the full AN-04 goal remains active.
