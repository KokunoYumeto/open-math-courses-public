# Distributions on limiting broken rays

Read [the proof](distributions-on-limiting-broken-rays.html) or edit [its source](distributions-on-limiting-broken-rays.md). For an injective uniform limit of finite transverse broken rays with interior endpoints, the lesson constructs a continuous compactly supported distribution with zero actual Dirichlet trace. Its full boundary wavefront is exactly the positive cone over the prescribed curve; the forcing wavefront consists exactly of the two endpoint rays. Smooth test families, changing-section orders, completeness and the Baire estimate are proved explicitly.
