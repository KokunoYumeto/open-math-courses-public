# One scalar test when all boundary tangential directions are allowed

Read [the proof](one-scalar-test-when-all-boundary-tangential-directions-are-allowed.html) or edit [its source](one-scalar-test-when-all-boundary-tangential-directions-are-allowed.md). On a manifold with compact boundary, one fixed scalar full finite-order test controls bounded complete target families when the allowed cone contains every boundary tangential direction. Interior and boundary kernels, cross-chart residuals, differential inputs and the original Banach remainder remain in the estimate.

A bounded positive model and a positive residual sandwich have a smooth interior commutator. A local auxiliary inverse, exact support buffers and a twice-transposed quadratic-form estimate give the global scalar norm. The prerequisite proof index gives the earlier results used here. Run `python -B model_check.py` and `python -B figures/build_figure.py` for the supporting identities and diagram.

This component requires every boundary tangential direction in the allowed cone. The complementary missing-direction case and general observation estimate are treated in [general scalar family and observation estimates](../20261017-angular-output-reserve-assembly/scalar-tests-from-a-missing-tangential-direction.html).
