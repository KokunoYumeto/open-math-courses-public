# Stable Airy coefficients and spatial localization

Read [the lesson](stable-airy-coefficients-and-spatial-localization.html) or edit [its source](stable-airy-coefficients-and-spatial-localization.md). A smooth moderate energy weight permits spatial cutoffs and ordinary pseudodifferential operators. An exact change of coefficients replaces the raw exponentially weighted pair by a decaying-mode coefficient and one normalized boundary coefficient, preserving the actual H1 construction and weak traces.

The prerequisite proof index gives the exact earlier results used in the arguments. Some prerequisite proofs are external readings linked by that index.
