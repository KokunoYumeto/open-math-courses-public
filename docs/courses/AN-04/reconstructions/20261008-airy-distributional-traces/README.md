# Distributional Airy kernels and their boundary traces

Read [the complete proof](distributional-airy-kernels-and-boundary-traces.html) or edit [the source](distributional-airy-kernels-and-boundary-traces.md). The normalized Airy kernels act continuously on compact distributions, with all normal derivatives and genuine value and conormal boundary limits. The proof constructs distributional Dirichlet and Robin parametrices with smooth PDE residuals and gives an explicit finite-loss Sobolev bound.
