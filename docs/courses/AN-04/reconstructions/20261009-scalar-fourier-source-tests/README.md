# Scalar source tests from compact logarithmic kernels

Read [the proof](scalar-source-tests-from-compact-logarithmic-kernels.html) or edit [its source](scalar-source-tests-from-compact-logarithmic-kernels.md). A positive Schwartz Fourier floor has an exactly compact logarithmic difference kernel. Complete right factorization gives one scalar residual test in every boundary dimension. Adding a positive conic multiplier gives one scalar finite-order test under the explicit whole-input patch condition, and one scalar source test for the local H2 regularized graph.
