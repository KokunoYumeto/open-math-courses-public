# Quadratic normal errors and removal of a boundary regularizer

Read [the complete lesson](quadratic-normal-errors-and-regularization.html) or edit [its source](quadratic-normal-errors-and-regularization.md). It bounds the full complex quadratic normal error with all three parametrix tails, constructs legal tests at any finite b-order and proves removal from a fixed-width uniform estimate.

Every regularizer derivative is controlled. Supported distribution convergence includes tests nonzero at the boundary. The Hilbert argument retains exactly the norm supplied by the uniform estimate.

The prerequisite proof index gives the exact earlier results used in the arguments.
