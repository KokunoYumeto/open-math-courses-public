# Cohomology of quasi-coherent sheaves

Eighteen lessons on sheaf cohomology, proper schemes, formal geometry, duality and GAGA, with 108 solved exercises.

[Read online](https://kokunoyumeto.github.io/open-math-courses-public/courses/AG-QC/). Editable Markdown is in `src/`; individual and cumulative TeX is in `files/`. Run `python -B build.py` to rebuild the owned reader; Python3, markdown-it-py and Pandoc are required.

Human sources and AI authorship accompany the lessons. See `COMPONENTS.json` and `licensing.html` for the CC0 teaching material, the credited Demailly/Siegel adaptation under the author’s custom OpenContent permission, and reader runtime notices.
