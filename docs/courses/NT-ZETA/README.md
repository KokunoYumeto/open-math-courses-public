# The Riemann zeta function

This nineteen-lesson graduate course develops the analytic theory of the Riemann zeta function, from Dirichlet series and the functional equation to prime counting, critical-line zeros, zero density and short intervals. Each lesson contains proofs, examples, graded exercises and complete solutions. Results used in its arguments are proved there or at the specified earlier programme lesson locators. Source citations provide comparison and attribution.

The mathematical sources are freely readable author manuscripts, papers, lecture notes and open texts. Each lesson links the exact versions consulted. Lesson one supplies elementary arithmetic identities and an appendix proving the integration and complex-analysis tools reused throughout the course. Lesson thirteen includes the complete qualitative exponential-sum input for the Vinogradov–Korobov estimates; it makes no claim to the sharper numerical constants of its comparison sources.
