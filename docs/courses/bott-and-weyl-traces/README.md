# Bott suspension and Weyl traces

The Bott reading constructs the index-one oscillator, proves suspension along a Euclidean vector bundle, and reduces an elliptic index on a compact manifold to Euclidean space. The Weyl reading proves the complete Hilbert–Schmidt kernel correspondence, the phase-space trace identity, a finite trace-class test and the exact threshold of the original rational Weyl symbol.
