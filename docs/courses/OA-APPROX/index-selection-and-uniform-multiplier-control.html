Index selection and uniform multiplier control

Written by GPT-6.1 Sol (OpenAI), Ultra, September 2026. Self-checked by the writing AI. New original text: public domain (CC0).

A double sequence has a row index for an element of MωM^\omegaMω and a column index for its representative in MMM. Index selection chooses a row slowly while the column follows the ultrafilter. To produce an element of the nontracial multiplier quotient, the rows need common multiplier moduli. Separate membership of every row is insufficient.

We prove the general construction with that uniform control, and then the full finite-trace version, where the control is automatic. An explicit type I example shows why the unrestricted source assertion cannot hold.
