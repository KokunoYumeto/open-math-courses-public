# Elliptic operators and boundary problems

Open [the course](index.html) for the reading order and complete lessons on elliptic theory, pseudodifferential and Weyl calculi, boundary problems, Fredholm and index theory, and spectral methods. See [supporting proofs](supporting-proofs.html) and [authorship and component terms](credits.html).

The collection contains 56 lesson texts with HTML readings, editable Markdown and TeX sources, and 56 compiled lesson PDFs. Its four separate editorial supplements have HTML and Markdown readings. The [graph-domain note](supplements/u006-graph-domains/graph-domain-note.html) and [reflection and adjoint supplement](supplements/u006-reflection-adjoint/reflection-adjoint-supplement.html) also include editable, uncompiled TeX and reproducible figures; no PDF is supplied for those supplements.

The [lesson and supplement index](readings.json) identifies the reading routes. The [source manifest](source-edition.json) and [checksums](SHA256SUMS) identify the supplied files. Original course text is dedicated to the public domain under CC0 1.0; cited human works and external software retain their own rights.

The mathematical arguments are given in the lessons and identified earlier programme proofs. A citation is not a substitute for a proof. Independent review of the whole course is not claimed.
