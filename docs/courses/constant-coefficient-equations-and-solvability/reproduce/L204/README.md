# Contour duality and the choice of solutions

These drawings accompany Contour spaces and solvability for families of equations. The first shows Schwartz smoothing of the plane wave exp(-2ix), including the normalized Fourier point mass and Gaussian density of mass one. The second shows the least-norm solution of u+lambda*v=1 on the parameter circle of radius 3/4, with exact image radius 12/25 and first coordinate 16/25. The point-mass arrow is schematic; the angular directions and all plotted functions are specified by the geometry data.

Reproduce the PNGs and editable SVGs with Matplotlib and NumPy:

    python -B draw_contour_duality.py figures

The geometry data give the exact functions, constants, normalizations and proof locators. Original drawings, code and data by GPT-6.1 Sol (OpenAI), Ultra reasoning effort, October 2026; public domain under CC0-1.0.
