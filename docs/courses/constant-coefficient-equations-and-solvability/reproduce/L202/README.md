# Exceptional carriers and differentiation of rational families

Run `python -B exceptional-carrier-figures.py` with Matplotlib and NumPy to reproduce the two PNG and editable-text SVG illustrations. The JSON file gives exact functions, parameter values, symbols, escape directions and carriers. Use `--overwrite` after an intentional change to the figure source.

The first figure shows three exact slices of a bounded rational family and its parameter derivative. The second compares the exceptional carriers of elliptic, transport and wave symbols in two dimensions. Finite drawing windows do not restrict the underlying cones. The lesson proves the limiting and arbitrary-polynomial statements; the plots illustrate the displayed exact models.
