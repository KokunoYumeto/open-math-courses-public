# Noncharacteristic cones and weighted adjoint words

These original diagrams accompany *Noncharacteristic directions and microlocal regularity*.

Figure 1 shows the exact frequency cones, output covector, length threshold and sample integration points used in Lemma 4.1 and Exercise 3. It illustrates the two integration regions and does not represent the wavefront set of a particular forcing. Circle boundaries are sampled parametrically; the cone inequalities and separation constant are given exactly in the JSON data and the proof.

Figure 2 counts retained and first-crossing ordered words in the finite inverse, equations (EE14)–(EE16) and Exercise 2. The script enumerates the finite ordered compositions and checks the exact counts 28 and 57. The operators are not assumed to commute.

Run `python -B microlocal-ellipticity-figures.py` with NumPy and Matplotlib to reproduce both PNGs, both editable-text SVGs and the JSON data. The original diagrams, data and code are dedicated to the public domain under CC0 1.0 Universal. The full lesson supplies every mathematical hypothesis, estimate and exercise solution.
