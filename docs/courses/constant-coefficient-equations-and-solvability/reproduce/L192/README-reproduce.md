# Reproduce the root and component figures

Run python -B check-and-figures.py with Python,SymPy,NumPy and Matplotlib.
The code performs257 exact concrete polynomial,Sturm root-count,multiplicity and rational isolation checks and creates two original diagrams as PNG and SVG. geometry.json records exact algebraic isolating intervals and plotted coordinates.
