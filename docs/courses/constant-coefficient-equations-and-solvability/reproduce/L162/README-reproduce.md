# Frequency-selective singularities and smooth convolutions

The formal chapter proves a compact continuous but not C1 construction with one prescribed singular point, exterior logarithmic Fourier collapse, and a proper zero profile on selected centers. Its peaked smooth kernels, complete function space and Baire argument are fully proved. It then proves all directions of the smooth-convolution characterization, including a continuous nonsmooth factor in any small support ball.

The learner chapter contains four worked examples and ten fully solved exercises. The figures show a concrete smooth probability seed, its transform powers, and exact comparison functions for the evaluation weight. They do not depict a computed Baire-selected function.
