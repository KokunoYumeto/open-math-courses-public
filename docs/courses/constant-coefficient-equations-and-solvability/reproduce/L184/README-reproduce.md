The main formal chapter proves the exact affine/projective tube comparison, center factor two, positive normal coefficient one, affine scalar-fiber splitting and logarithm argument. The learner has four examples and eight fully solved exercises totaling 100 points. The accompanying analytic reading retains every mathematical expression and solved exercise in the original authored tangent/contour/polynomial-continuation proof body. Run with Python 3, NumPy, mpmath and Matplotlib:

    python -B -X utf8 affine-cycle-check-and-figures.py

The code generates both PNG/SVG figures and exact geometry data. One drawing uses the actual negatively oriented affine filling disc for F=tau, with fixed imaginary coordinate -7/20 and its exact projective image. The other distinguishes center multiplicity, the relative-disc normal map and the forgotten scalar-fiber model. Every diagram specifies whether it is an exact coordinate plot or a map/class diagram.

The 5713 finite identities supplement the complete proof. They verify parity factors, homogeneous pole degrees, affine nonvanishing, projective normal determinants, positive radial scales and the canonical/scalar logarithmic periods. They are not a numerical proof of the general theorem.
