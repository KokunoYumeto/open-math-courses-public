# Reproduce the analytic-boundary checks and figures

Run with Python, mpmath, NumPy and Matplotlib:

    python -B -X utf8 analytic-boundary-check-and-figures.py

The script checks exact finite-Taylor signs, independent scalar integrals at 90 decimal digits, separating-vector coordinates, tensor Fourier constants and point-jet multiplier signs. It renders two PNG/SVG diagrams. The complete mathematical proof and all eight fully solved exercises remain the authority; finite checks supplement them.

The complex-plane panel is explicitly a compact weighted parameter-integral schematic, with the exact model, support, Taylor order and damping phase recorded in the geometry JSON. The polar panel is a separate two-dimensional model. The scalar panels display the full-half-line remainder bound and the exact normalized top-face maximum, with distinct positive parameters stated in the caption. Figure sources and exact geometry are retained; SVG dates are omitted and the hash salt is fixed.
