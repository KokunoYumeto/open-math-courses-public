# The left-shift equation

This illustration accompanies Power series and analytic lifting in Banach spaces, Example 4.2. Coordinates start at zero. The solution is f(z)=(0,1,z,z^2,...); its left shift minus z*f(z) equals e_0. For |z|<1 its l1 norm is exactly (1-|z|)^(-1). The dots denote the entire geometric tail.
