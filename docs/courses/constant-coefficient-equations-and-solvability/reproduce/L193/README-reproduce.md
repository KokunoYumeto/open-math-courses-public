# Reproduce the weight and root diagrams

Run python -B check-and-figures.py with Python,SymPy,NumPy and Matplotlib.
The code performs701 exact concrete checks on168 parameterized models,scaled limits,root-orbit identities and rational Rouche bounds,then creates two original diagrams as PNG and SVG. geometry.json preserves the exact support and root coordinates.
Read the full proof for the general holomorphic germ theorem;finite computations do not replace it. The learner has four examples and eight complete solutions totalling100 points. Original material is CC0;linked providers and fonts keep their actual terms.
