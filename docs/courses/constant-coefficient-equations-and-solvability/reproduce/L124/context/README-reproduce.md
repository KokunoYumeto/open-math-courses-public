# Projective exhaustion and the tube-injection prerequisite

Open `index.html` through a local HTTP server. The main reading is `projective-exhaustion-and-the-finite-chain-tube-receiver.html`, with its editable Markdown source beside it. Supporting readers are under `providers/`, and their sources are under `sources/`. The packet includes the selected complete duality and tubular-neighbourhood sections identified in those readers' notices.

This partial prerequisite gives elementary arguments, the stated normal Thom and tubular-neighbourhood construction, worked examples and solutions. The tube-injection deduction assumes the declared ordinary Morse handle input H. It does not establish H, general rational-form spanning, the affine/projective C8 comparison or component constancy. Each supporting reading states its authorship and component terms.
