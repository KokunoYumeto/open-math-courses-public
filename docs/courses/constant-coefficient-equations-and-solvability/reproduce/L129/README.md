# Canonical compact connecting map

Read [the complete original proof](canonical-compact-connecting.md). It constructs the canonical compact singular-cochain closed–open connecting map, proves the support-kernel comparison using a proper normal collapse and face-compatible subdivision, and compares the rational map with the specified normal-circle formula. Three worked examples and six complete solutions are included.

The final rational tube comparison retains the exact selected DGCHAR orientation/right-cap and ordinary Thom entries, and the CO/FC ordinary CD034 comparisons on the actual spaces and their compact-set complements. Integral tube comparison, affine C8, rational-form spanning, component constancy require their additional mathematical arguments.

The original figures have reproducible sources in make_figures.py and exact labels and coordinates in figures/geometry.json. The first is a specified two-dimensional radius slice of a four-dimensional example; the second displays actual cochain and cohomology maps. Run the renderer with the supplied Python environment and matplotlib. The new proof and these original figures are dedicated under CC0. Referenced external works keep their own terms and credits.

The package includes the proof source, figures, exact geometry, renderer and applicable component notices.
