# Reproduce the jet and support-geometry checks

Run python -B check-and-figures.py with Python, SymPy, NumPy and Matplotlib.
The script checks 89 exact rational or symbolic identities and creates two original figures as PNG and SVG, with exact geometry.json.
It does not replace the full analytic uniqueness argument. Read the formal proof and the exact first-order provider, Fundamental solutions in shrinking cones, Sections7.1-7.2.
The learner gives four original examples and eight complete solutions totalling100 points. Sources and figures are CC0; linked providers and fonts keep their own terms.
