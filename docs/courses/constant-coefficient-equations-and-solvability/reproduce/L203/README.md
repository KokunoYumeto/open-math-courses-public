# Uniform contours and separated derivative masses

These drawings accompany One contour for a compact family of equations. The complex-plane model shows the exact root disk and bounded Borel shift of Example 6.1 at complex-translation radius zero. The logarithmic model shows Lemma 3.1 for Q(w)=(w+3)^2, with derivative masses 9, 6, 2 and candidates 1, 64, 4096, 262144. It illustrates the finite-gap step; the later uniform-transfer constants are chosen separately in the theorem.

Reproduce the PNGs and editable SVGs with Matplotlib and NumPy:
