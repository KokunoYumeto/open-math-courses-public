# Characteristic-ray illustrations

This folder contains two original figures for *Characteristic rays and directional kernels*, together with their editable SVGs, numerical parameters and reproducible Python source.

The imaginary-frequency figure shows an exact complex graph for the polynomial \(\zeta_2+2i\) and the exponential decrease at the base point \((1,0)\). The line-and-covector figure distinguishes the characteristic frequency \((1,0)\), its principal gradient \((0,1)\), and the attached positive covectors along the line \(x_1=0\). Captions in the lesson state the mathematical scope.

Run `python characteristic-ray-figures.py` with Python, NumPy and Matplotlib. The program writes PNG and editable-text SVG figures into `figures/`. Existing figure bytes must match the reproduced bytes. The program, parameter data and original figures use the CC0 terms in `LICENSE.txt`.
