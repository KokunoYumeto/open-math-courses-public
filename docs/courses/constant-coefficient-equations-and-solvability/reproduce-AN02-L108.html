Reproduce the normal-root-distance figure

This original figure and its accompanying learner lesson are CC0-1.0. The linked supporting readings retain their own licences and notices.

Read the figure and its mathematical caption; download the exact learner source.

Save the plotting source and reproduction wrapper in the same directory. The PNG, SVG and geometry downloads below use the names produced by the wrapper.

  • an02-l108-normal-root-distance.png
  • an02-l108-normal-root-distance.svg
  • an02-l108-render-normal-root-distance.py
  • an02-l108-normal-root-geometry.json
  • an02-l108-reproduce-normal-root-distance.py

Use Python with NumPy and Matplotlib. From that directory, run:

python an02-l108-reproduce-normal-root-distance.py

The original plotting source writes generic filenames in a temporary directory. The wrapper verifies the exact PNG, SVG and geometry bytes before copying them to the named files above. A dependency version that changes an output will fail the check before any named output is replaced.
