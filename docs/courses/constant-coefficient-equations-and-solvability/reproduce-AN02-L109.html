Save the original plotting source and reproduction wrapper in the same directory. The named PNG, SVG and geometry files are available here:

  • an02-l109-hyperbolic-first-support.png
  • an02-l109-hyperbolic-first-support.svg

Use Python with NumPy and Matplotlib. From that directory, run:

python an02-l109-reproduce-hyperbolic-first-support.py

The original plotting source writes generic names in a temporary directory. The wrapper checks the PNG, SVG and geometry against their exact expected bytes, then writes the named outputs above.
