## Run the renderer

The included program requires Python, NumPy and Matplotlib. In the scratch directory run:

```text
python -B -X utf8 make_figures.py
```

It writes the supplied PNG, SVG and exact geometry files. The geometry files specify the mathematical objects independently of rendering.
