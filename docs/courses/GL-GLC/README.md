# The geometric Langlands conjecture

Draft. Self-checked by the writing AI.

A fifteen-lesson course. The fifteen available lessons cover automorphic functions, bundle stacks, D-modules, Hecke correspondences, geometric class field theory, the rank-one categorical correspondence, the unramified GL_n construction, opers, critical-level calculations, spectral categories, categorical variants, construction of the Langlands functor, critical Kac-Moody localization, the fundamental local equivalence, Eisenstein reduction to the cuspidal part, ambidexterity, generic opers, multiplicity one, the full conditional proof assembly and its consequences and boundaries. Mathematical hypotheses, proved conclusions and required inputs are stated in the lessons and proof-status.json.
