# Figure and font terms

The original mathematical figure, its Python renderer and generated numerical data are dedicated to the public domain under CC0 1.0 Universal. No external image, external numerical dataset or scanned page is included.

Text uses the DejaVu Sans family distributed with Matplotlib. The exact bundled font terms are retained in FONT_LICENSE_DEJAVU.txt. The SVG embeds glyph outlines; those glyph components retain their font terms. The font itself is not redistributed in this folder.

Reproduction: run render.py with Python, NumPy and Matplotlib. It regenerates the PNG, SVG and data.json locally. Mathematical formulas and exact constants are specified in the renderer and data. No network access is used.
