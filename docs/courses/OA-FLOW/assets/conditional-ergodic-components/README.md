# Conditional ergodic components

Run `render_components.py` with Python and matplotlib to reproduce the PNG,
SVG and exact fraction data. The script checks the probability masses,
pushforward density ratios, unitarity identity and involution identity.

The diagram represents the two finite conditional systems in OA-FLOW ED,
equations (E1)–(E5). Its arrows are the group action inside each fibre;
the two base points are fixed. The conditional measures are ergodic and
quasi-invariant but not invariant.
