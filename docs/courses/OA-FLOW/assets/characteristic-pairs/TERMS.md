# Diagram sources and terms

The Python source, exact arithmetic diagnostics, mathematical diagrams and original explanatory labels in this directory are released under CC0-1.0.

Run python render.py with Python 3, NumPy and Matplotlib to regenerate both PNG and SVG files and diagnostics.json. The SVG hash salt and timestamp policy are fixed. The script uses installed DejaVu runtime fonts; no font files are copied or bundled. Third-party runtimes and installed fonts retain their own terms.

The exact mathematical models are proved in ../../src/OA-FLOW-CPP.md, equations CP2, CP7–CP10, CP30–CP34 and Section 8. The human source for the underlying questions is Masamichi Takesaki, Theory of Operator Algebras III, Chapter XVII, §3, Exercises 1–3, printed pp.292–293; Proposition 3.13 and Definition 3.14, pp.283–284, identify the finite-period obstruction. No source page, drawing, font or source wording is reproduced.

The finite arithmetic checks verify the implemented sample data and the six-element conjugation diagnostic. They do not replace the proofs for general groups and all integer coordinates.
