# Dominant weights: motion, order and cancellation

Original figure, drawing source and mathematical data: CC0-1.0 to the extent of rights held. DejaVu Sans has its separately retained license in FONT-LICENSE.txt. No external image or source figure is used.

Reproduce with Python 3, NumPy and Matplotlib by running python render.py. The script reads data.json beside itself and writes dwc-models.png and dwc-models.svg. The fixed PNG records the inspected layout; SVG text remains editable. The script also copies the installed DejaVu license.

Panel A plots the exact densities exp(q) and 2 exp(q) on a bounded window. The finite plotting grid is not a proof about arbitrary positive operators; the proof is DWC5.c-DWC5.g. Panel B contains exact Gaussian-integer matrices and an exact common divisor sqrt(2), not numerical approximations. Panel C shows twelve values of an explicitly proved bijection of the entire set of pairs of nonnegative integers; the strong-star row limit and whole-cone weight identity are proved in DWC5.p-DWC5.u. Panel D distinguishes the two independent hypotheses and uses a rank-one projection to distinguish the usual trace from twice that trace.

Proof locators: OA-FLOW-DWC Sections 5-6. Earlier foundations: OA-FLOW-TW#tw-1, #tw-2, #tw-3, #tw-5; OA-FLOW-CZ#cz-0, #cz-2, #cz-5, #cz-7; OA-FLOW-BC#bc-5, #bc-6; OA-FLOW-PC#pc-5; OA-FLOW-FF#oa-flow.ff.2, #oa-flow.ff.3; OA-FLOW-ND#nd-multiplication, #nd-weyl-proof, #nd-tensor.
