# Supported commutants and state normalization

The lesson's original diagram, drawing code and parameter data are dedicated to CC0-1.0. The diagram is generated from the exact rational densities in MC21; it contains no source-publication images. Its upper panel depicts the maps proved in MC16–MC20, with all relative commutants taken in the stated support corner.

The renderer uses Matplotlib and the existing DejaVu Sans regular and bold font files in the course's `typeiii-zero-decomposition` asset directory. Those fonts retain their original DejaVu/Bitstream terms in that directory's `FONT-LICENSE.txt`; they are not placed under CC0. No font copy is included here. The SVG stores glyph outlines for faithful display and contains no external images. Matplotlib and Python retain their own software licenses; neither library is bundled.

Reproduce the SVG and PNG with `python -B render.py` from the published asset layout, or supply `--font-dir` with the existing font directory. `data.json` gives the exact rational values, support-corner inclusions and proof locators. The renderer checks the state mass with exact fractions before drawing.
