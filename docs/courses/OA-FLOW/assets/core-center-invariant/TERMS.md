# Figure terms

The original renderer, illustration and model data are dedicated under CC0-1.0 to the extent of rights held. No source-paper image, page, font or other external artwork is included. Installed DejaVu Sans supplies the rendered lettering and retains its own terms.

Reproduce with `python -B render_core_cut.py`. Dependencies: NumPy and Matplotlib. The SVG stores paths for lettering; no font file is redistributed.

The figure illustrates the complete finite-cut, mass, inner-invariance and scalar-covariance proofs in *A finite spectral cut of a core density*, equations CI3–CI6 and CI11–CI12. It uses a finite matrix example of that construction and makes no separate claim about the type III orbit classification.
