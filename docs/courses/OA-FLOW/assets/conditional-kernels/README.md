# Fractional-part conditional measures

`render_fractional_part.py` reproduces the PNG, SVG and exact rational data with
Python and matplotlib. The figure shows one entire infinite fibre through a
finite illustrated window. Both omitted probability tails are explicitly
accounted for. Equations (E1)–(E10) in OA-FLOW L75 prove the displayed formulas.

The original figure, code and data are dedicated under CC0-1.0. The DejaVu font
has its own terms, retained in `FONT_LICENSE_DEJAVU.txt`; those terms are not
replaced by the CC0 dedication. The SVG stores the lettering as paths.
