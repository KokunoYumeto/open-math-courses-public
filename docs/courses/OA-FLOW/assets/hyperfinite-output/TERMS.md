# Tensor-interleaving figure

The original vector diagram is dedicated to CC0-1.0 to the extent of rights held. Its complete reproducible source is tensor-interleaving.svg. It uses no external image or bundled font. The six displayed tensor positions are a finite window of the exact bijection j(1,n)=2n-1, j(2,n)=2n. The full normal map and inverse are proved in [the lesson](../../OA-FLOW-HA.html#ha-interleaving), equations HA16–HA19.
