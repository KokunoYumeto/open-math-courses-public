# Fixed-centre components

Run `render_fixed_centre.py` with Python and matplotlib to reproduce the PNG,
SVG and exact data. The script checks the involution, central projections and
fixed-space dimensions by integer calculations on matrix-unit orbits.

The figure shows the exact finite example in OA-FLOW L42, equations (E1)–(E6).
It distinguishes the whole centre, its fixed subalgebra and the full fixed
operator algebra. The two base points belong to the decomposition over the
fixed centre. They do not label the three summands of the original centre.
