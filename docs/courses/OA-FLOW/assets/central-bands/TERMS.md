# Central bands and the global carrier

The lesson's original diagram, drawing code and parameter data are dedicated to CC0-1.0. The diagram is generated from the exact rational cocycle in CB34; it contains no source-publication images. Its second panel depicts the maps proved in CB24–25 and CB30–31, with a finite band window explicitly identified as a diagram.

The renderer uses Matplotlib and the existing DejaVu Sans regular and bold font files in the course's `typeiii-zero-decomposition` asset directory. Those fonts retain their original DejaVu/Bitstream terms in that directory's `FONT-LICENSE.txt`; they are not placed under CC0. No font copy is included here. The SVG stores glyph outlines for faithful display and contains no external images. Matplotlib and Python retain their own software licenses; neither library is bundled.

Reproduce the SVG and PNG with `python -B render.py` from the published asset layout, or supply `--font-dir` with the existing font directory. `data.json` gives the exact rational values, central coordinate swap and proof locators. The renderer checks the ordered cocycle with exact fractions before drawing.
