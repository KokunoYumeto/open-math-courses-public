# Relative commutants: four exact mechanisms

The original mathematical diagram, drawing source and data are dedicated to the public domain under CC0-1.0, to the extent of rights held. The text uses DejaVu Sans; its separate license is retained in FONT-LICENSE.txt. No external image assets are used.

Run python render.py from any directory with Python 3 and Matplotlib available. The script reads data.json beside itself, writes rcc-models.png and rcc-models.svg there, and copies the installed DejaVu font license to FONT-LICENSE.txt. The PNG is the fixed reference render; SVG text remains editable.

The exact shear polygons are closed supports for only n=0,2,4; their interiors carry positive smooth bumps. The marked centers have the exact strictly positive values in data.json. The decay statement is the analytic bound RCC7.aa, not an inference from these three samples. The finite-subset diagram contains four members of an uncountable directed family and does not depict a countable exhaustion.

All matrix phases, Fourier signs and translation coordinates are exact. The centralizing product is pi_phi(h^(-it)) lambda(t), the Fourier character is exp(-itq), and the translation action is f(q-s). The scalar cocycle exp(ibs) is the central coboundary of exp(ibq).
