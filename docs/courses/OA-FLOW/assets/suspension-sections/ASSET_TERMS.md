The signed deck map for a local suspension orbit segment, with exact rational roof and hitting coordinates. The drawing is independently constructed and contains no source-book figure or layout.

The return-section diagram compares a unit suspension roof with two half-roof return levels. Its editable SVG gives the coordinate identification and the finite-order eigenvalue distinction between the return transformations. It contains no source-book figure or layout.

The signed-deck SVG uses DejaVu Sans font outlines; the font retains its separate terms, reproduced in LICENSE_DEJAVU. The return-section SVG uses live text with system-font fallbacks and contains no font files.

Run `python render_signed_deck.py` with matplotlib to regenerate the signed-deck PNG, SVG and exact-check JSON. Constants use Python fractions and exact assertions. The return-section SVG is itself the editable vector source and can be displayed directly.
