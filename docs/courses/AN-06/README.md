# Spectra, resolvents and scattering

This course connects five questions: what a spectral measurement tells us, how escape selects a real-energy solution, which perturbations define the operator, whether observations reconstruct every continuous state, and which estimates survive a long-range limit.

Start with the [worked comparisons and proof routes](learning-route.md), or open the [offline reader](reader/index.html). The course contains 51 lessons and 255 graded exercises with complete solutions. Its five routes connect exact models, analytic estimates and geometric constructions.
