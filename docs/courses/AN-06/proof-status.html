Prerequisite readings

Read each prerequisite before the lesson that uses it. The lessons give the exact statements, hypotheses and proof locations needed for their arguments. Start with the course reading guide.

For integration and Fourier analysis, begin with Euclidean measure, coordinate integration and surface measure, then the Fourier reading. For polynomial critical values, use Noetherian rings and separability. For wave kernels, follow scalar calculus, phase geometry, composition, pullback and transport in that order.
