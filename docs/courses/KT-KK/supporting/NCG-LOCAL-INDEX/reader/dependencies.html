Prerequisite proofs

Written programme lessons supply these foundations. The readable pages contain the exact proof sections used here, with their original licenses and source downloads. Start with positive spectral calculus for the compact decomposition; use the Banach and trace-ideal proofs for norm limits, Fredholm stability for finite defects, and cyclic cohomology for the index pairing.

  • Banach estimates, quotient spaces and compact parameter arguments (CC0-1.0)
  • Cyclic cohomology: traces, differentials and symmetry (CC0-1.0)
  • The index theorem for measured foliations (CC0-1.0)
  • Spectral measures and operator domains (CC0-1.0)
  • Trace ideals and cyclicity (CC0-1.0)
  • Fredholm stability and compact parametrices (CC0-1.0)
  • Symbols under coordinate and bundle changes (CC0-1.0)
