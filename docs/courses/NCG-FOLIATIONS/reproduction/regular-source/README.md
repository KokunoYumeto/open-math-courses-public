# Regular source and metric-isotropy figures

The mathematical diagrams and this generator are original expression dedicated under CC0 1.0 to the extent of rights held. No external artwork is incorporated.

Run `python -B draw.py` with Python, NumPy and Matplotlib to reproduce the two SVG and PNG pairs in the course figures directory. SVG hash salt and metadata are fixed. A separate output directory may be selected with `--output PATH`.

The separator diagram is an algebraic schematic of RTP.3–13, including both compact ideals, the completed ordered module and exact creation comparison. The tangent diagram uses exactly MI.1: A e2 = (0, 1/3, 2 sqrt(2)/3), B e3 = (2 sqrt(2)/3, 0, 1/3). These are vectors at the actual fixed quaternion n=1, not points of the foliation drawn in space. The drawn tree is only its radius-two ball; the proofs retain the entire tree. MI.7–10 give the actual metric isotropy, strict averaging bound, reduced cycle and completed domain. Neither drawing supplies an arbitrary nonisometric construction.
