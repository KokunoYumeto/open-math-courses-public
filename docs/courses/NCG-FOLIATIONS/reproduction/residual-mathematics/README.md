# Probability-code illustration

The script draws the first two levels of the fair binary probability code and the exact Borel support condition from Theorem K.4A. Root mass1, child masses1/2 and grandchild masses1/4 are exact. The eventual-zero example has probability0 for this code; the proof in the lesson treats all levels and the endpoint Bernoulli codes.

Run `python draw_figures.py` from this checkout with Pillow12.2.0 installed. The default output is the kernel lesson's figures directory. Use `--output DIR` for a separate output directory. Keep the existing finite-kernel-prerequisite/fonts/DejaVuSans.ttf and its notice at the stated relative path. The script creates PNG and editable SVG; it includes no software binary.
