# Nonisometric normal phases

Original mathematical expression, native vector diagram and generators: CC0-1.0.

Run `python generate.py`, then `node render.cjs` with Playwright installed. `PLAYWRIGHT_MODULE` and `CHROME_EXECUTABLE` can select local runtime paths. PNG and SVG are written to `../../figures`; `node render.cjs --check-only` validates label bounds without replacing PNG.

NRA.1–NRA.10 prove the degree-one positive reduced graph class. AP.1–AP.12 give the actual anisotropic degree-two half-density countertest and exact normalized Clifford directions. The gap is computed from the exact formulas in data.json before rendering. Software and installed fonts retain their own terms; no external artwork, font bytes or glyph outlines are incorporated.
