# Reproducing the source-column diagram

Run `python draw_source_column.py` with Python, Matplotlib, NumPy and Pillow installed. PNG and SVG are written to the course figures directory. Use `--output-dir DIRECTORY` for another destination.

Figure 11H.1 of **K-theory of the leaf space** shows the actual compact-fibre source column, the exact smooth chart projection, the antipodal sphere seam and the two infinite-multiplicity frequency sectors. The base-circle plot samples 2,001 points using support radius 0.36 inside chart radius 0.38. The proof is in Theorem 11H.1, equations SC.1–SC.21 and solved Exercises 128–130. Leaf circles are schematics; sphere disks are meridian projections.
