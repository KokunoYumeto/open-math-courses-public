# A proper image and its nonproper retraction

Theorem 5.34 and Exercise 30 in *Transverse measures of foliations* compare the full transverse functionals on the one-unit groupoids 1 and Z. The proper inclusion sends both finite masses 1 and 2 to the same infinite-valued functional. Since the projection composed with the inclusion is the identity, no image rule on all measurable functors can recover both masses.

Figure 5.34 shows the exact arrow maps, complete functional values and finite-window integrals c(2N+1), for b=1. The finite plotted windows illustrate the unbounded growth; the lesson contains the complete infinite proof. These are abstract groupoids, with no assertion that the diagram itself realizes a foliation.
