# Reproduction

*K-theory of the leaf space*, Section 11AL. The actual adjointable factor S-prime=h^beta B, with 1/2-alpha<beta<1/2, is a sufficient premise for a compact derivative of h^alpha. That factor has not been proved for the actual orbit column. The strict exponent region and quarter-power integral constants are exact.

Use Python 3.13.9 and Pillow 12.2.0. Run `python -B draw_fractional_bridge.py --output-dir out`; `--resources` selects the adjacent labelled-geometric-kernel resources if relocated. The public resources provide the unchanged font, full font notice, CC0 dedication and Python/Pillow notices. Compare PNG/SVG with `../../figures/` and FRACTIONAL-POWER-CHECKS.json with this folder. No private files are read.

The finite checks verify the displayed examples and constants. They do not prove an infinite-dimensional theorem, a module-domain assertion or a missing physical premise. The complete proofs and graded solutions are in the lesson.
