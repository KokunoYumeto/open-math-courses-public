# An anchored proper algebra and a continuous calibrated family

Section 11Z of *K-theory of the leaf space* proves the actual groupoid vertex geometry, the proper continuous nearest-face algebra, its continuous shifted exterior family, the whole-base ordinary positive product and the original-anchor deformation interfaces. Exercises 164–168 give complete solutions for 64 points. Section 11AA now proves the separately stated equivariant lifting condition. The general graph construction remains a distinct obligation.

Use Python 3.13.9 and the pinned package versions in requirements.txt with the bundled unchanged regular and bold fonts. Run `python -B draw_anchored_universal.py --output-dir OUTPUT` to regenerate PNG, SVG and the exact mathematical data, and `python -B self_check.py --output OUTPUT/checks.json` to run the finite model. The diagram's SVG date, hash salt and model seed are fixed. Compare regenerated bytes with the included PNG/SVG and figures/anchored-nearest-face-data.json.

The finite model is the action groupoid of C2×C2 on two units: the first factor exchanges units and the second is actual isotropy. It retains eight arrows, two integer labels per arrow, the range-fibre metric and the exterior permutation signs. It checks 2,040 simplex covariance identities and7,936 radius-one face-support samples, connected-origin agreement, Clifford compression, the even deficient line and actual source/range composition. These checks supplement the full proofs; finite samples do not establish infinite KK identities.
