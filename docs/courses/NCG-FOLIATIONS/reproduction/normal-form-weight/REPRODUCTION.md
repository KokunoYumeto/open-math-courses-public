# Smooth compact inverse and completed normal forms

*K-theory of the leaf space*, Section 11AJ, proves smooth compact inverse/resolvent control and an infinitesimal positive-order normal form estimate on the actual intrinsic jet field and its compact-frame quotient. A real rotating-block field separates this result from one-sided operator bounds and action-domain preservation. The physical graph operator remains unproved.

Use Python 3.13.9 and Pillow 12.2.0. Run `python -B draw_normal_form.py --output-dir out`; `--resources` selects the adjacent labelled-geometric-kernel resources if relocated. The public resources provide the unchanged font, full font notice, CC0 dedication and Python/Pillow notices. Compare PNG/SVG with `../../figures/` and NORMAL-FORM-CHECKS.json with this folder. No private files are read.

The five rational block cases n=2–6 check the two independent normalizations. The n=2 positive-order sample has C=1/2, a=1/4, remainder 8 and determinant 133200 for both signs. All displayed numbers are exact. The complete infinite block and section-domain proofs are CW.10–CW.12; the finite checks do not establish an infinite-dimensional theorem. One-sided boundedness is a possible sufficient input, rather than a required form of every solution to the original Dirac problem.
