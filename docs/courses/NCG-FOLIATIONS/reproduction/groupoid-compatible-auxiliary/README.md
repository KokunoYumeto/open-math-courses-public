# Coherent groupoid transfer and the proper weak cone

Section 11R of *K-theory of the leaf space* contains complete proofs of the actual descended-module unit restriction, the typed conditional transfer with the original local Bott normalization, the exact properness criterion for a compact-operator field coefficient, and the proper weak cone from a coherent continuous groupoid kernel. Exercises 150–153 give complete solutions. Kernel and Bott/Dirac factor existence throughout the general holonomy scope remain separate prerequisites.

Figure 11R.1 retains each algebra, coefficient, degree and ordinary/local restriction. Its geometric panel is the exact one-dimensional fibre slice L=1, b=1, v=-1/2, t=3/4; the image is v=1/2, t=3/4 and both excess heights are 1/2. It is a coordinate slice of the weak-field cone. figure-data.json records the exact sample and bounds.

Use Python 3.13.9 and the versions in requirements.txt. Keep both bundled fonts and FONT-NOTICE.txt beside draw_compatible.py. Run `python -B draw_compatible.py --output-dir OUTPUT` to produce PNG, editable SVG and figure-data.json. The vector uses font outlines; the PNG/SVG metadata retain the full font notice. No TeX installation, network data or source extracts are required. Complete component terms and runtime notices are supplied here.
