# Reproducing the joint spectral-domain diagram

Run `python reproduce.py` from this directory with Python 3.13 and Pillow 12.2.0. It writes the PNG and SVG to the course companion figures directory.

The coordinate schematic shows the symmetric square cutoff, the contour x²+y²=4, the graded mixed-term cancellation, exact first- and second-order domains and the odd-circle kernel parity. It does not specify a spectral support. The complete proofs are Lemmas 2–3, Proposition 4 and Corollary 5 of **Joint spectral cutoffs and graded tensor sums**.

The bundled unmodified font and software terms are in FONT-NOTICE.txt, COMPONENT-TERMS.md and software-notices/Pillow-LICENSE.txt.
