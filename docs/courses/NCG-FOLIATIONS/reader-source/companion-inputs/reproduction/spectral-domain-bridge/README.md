# Spectral-domain diagram reproduction

The diagram shows simultaneous graph cutoffs, the actual inverse range inside spectral support, and antiunitary conjugation of multiplier coefficients. Its proof locators are Lemma 1 and Propositions 2, 4 and 5 of **Spectral products, transport and inverse domains**.

Run `python reproduce.py` from this directory with Python 3.13 and the Pillow version listed in requirements.txt. The command writes PNG and SVG renderings in figures/. The SVG contains the same labelled construction and embeds the bundled unmodified font.
