Filtered stages and finite limits

Written and self-checked by GPT-6.1 Sol (OpenAI), Ultra reasoning effort, October 2026. Original text: CC0. Internal Ultra workflows contributed bounded proof and validation work; the course writer integrated and checked the result.

A finite list of representatives can be moved to one common stage of a filtered diagram. A finite list of equations can then be made true at a later stage. These two operations explain the quotient model for filtered colimits, the underlying set of a module colimit, and the commutation of filtered colimits with finite limits of sets. The converse theorem shows that this behavior detects filteredness itself.

Fix a universe \(\mathcal U\). The index of every Set or module colimit below is \(\mathcal U\)-small, and its values are \(\mathcal U\)-small. A finite category has finitely many objects and finitely many arrows. For that criterion, categories and their Hom sets are considered in an ambient universe. The elementary filteredness criterion itself does not impose smallness in the fixed working universe; smallness is needed when forming the stated Set colimits. Use the full proofs of small tagged unions, quotients and function sets, the general Set colimit and covariant represented singleton, and compatible families and finite limit tests. Modules are left modules over associative unital rings.

1. Bring a finite diagram to one object

A category \(I\) is filtered when it has the following three properties.

  1. It has at least one object.
  2. Given objects \(i,j\), there are an object \(k\) and arrows \(i\to k\), \(j\to k\).
  3. Given parallel arrows \(f,g : i\to j\), there is an arrow \(h : j\to k\) with \(hf=hg\).

The second condition brings objects together. The third repairs disagreement between arrows. Neither condition says that the chosen object or arrow is universal. For a partially ordered set, viewed as a category with one arrow \(i\to j\) when \(i\leq j\), parallel arrows already agree. Filteredness then means nonemptiness and a common upper bound for each pair. For instance \(\mathbb N\) with its usual order is filtered. More generally, a category with a terminal object is filtered: the unique maps to that object both give common targets and equalize parallel arrows.

Here finite category means that both its object set and its arrow set are finite. A diagram with finitely many objects can still have infinitely many arrows; the next assertion concerns finite categories in the stated sense.

Proposition 1.1. A category \(I\) is filtered if and only if every functor \(\phi : J\to I\) from a finite category admits a cocone. Thus some object \(k\in I\) has a family

\[ \begin{gathered} u_a : \phi(a)\longrightarrow k \quad(a\in J),\\ u_b\circ\phi(\alpha)=u_a \quad(\alpha : a\to b). \end{gathered} \tag{1.1} \]

For clarity, the compatible-family set in this statement is a limit of a contravariant Hom diagram. For a fixed \(k\), define \(F_k : J^{\mathrm{op}}\to\mathsf{Set}\) by

\[ \begin{aligned} F_k(a)&=\operatorname{Hom}_I(\phi(a),k),\\ F_k(\alpha^{\mathrm{op}})(u)&=u\circ\phi(\alpha). \end{aligned} \]

Then the families (1.1) form \(\varprojlim_{J^{\mathrm{op}}}F_k\). The assertion is that this set is nonempty for some \(k\). When \(J\) is empty its compatible-family set is a singleton for each existing \(k\); requiring such a \(k\) still tests nonemptiness of \(I\).

Proof. Suppose first that \(I\) is filtered. Choose an object of \(I\), even if \(J\) has no objects. Enumerate the objects of \(J\). Incorporate them one at a time: if arrows from the objects already incorporated end at \(c\), choose a common target \(c'\) of \(c\) and the next \(\phi(a)\). Postcompose the old arrows by \(c\to c'\), and use \(\phi(a)\to c'\) for the new object. After finitely many steps this gives an object \(c_0\) and arrows \(u_a^{(0)} : \phi(a)\to c_0\) for every object \(a\). These arrows need not yet respect the diagram.

Enumerate its nonidentity arrows as \(\alpha_1,\ldots,\alpha_m\). At step \(r\), write \(\alpha_r : a\to b\). The arrows \(u_a^{(r-1)}\) and \(u_b^{(r-1)}\phi(\alpha_r)\) have the same source and target. Choose \(h_r : c_{r-1}\to c_r\) equalizing them, and replace every component by

\[ \begin{gathered} u_d^{(r)}=h_r\circ u_d^{(r-1)},\\ u_b^{(r)}\circ\phi(\alpha_r)=u_a^{(r)}. \end{gathered} \tag{1.2} \]

Any equation installed at an earlier step remains true after this common postcomposition. Thus the final family satisfies every nonidentity-arrow equation. Identity equations hold automatically. If there are no nonidentity arrows, the initial family already suffices; if there are no objects, the initially chosen object and the empty family suffice. This constructs the cocone in every case. The same construction works for any finite graph of specified objects and arrows: enumerate its vertices and then its edges, with each edge imposing its one equation. There is no need to close the graph under compositions or assume it acyclic.

Conversely, assume every finite diagram admits a cocone. The diagram with empty domain supplies an object of \(I\). The diagram from the discrete two-object category, sending its objects to any specified \(i,j\), supplies a common target and two arrows to it. Finally use the category with two objects and exactly two nonidentity arrows from the first to the second. Send these arrows to specified parallel \(f,g : i\to j\). A cocone has components \(u_i : i\to k\), \(u_j : j\to k\) with \(u_jf=u_i=u_jg\). Its second component is the required equalizing arrow. All three filteredness conditions follow. \(\square\)

A category is cofiltered when its opposite is filtered. In its own arrow directions this means nonemptiness, a common source \(k\to i\), \(k\to j\) for each pair of objects, and an arrow \(h : k\to i\) with \(fh=gh\) for each parallel \(f,g : i\to j\). Applying Proposition 1.1 to the opposite categories gives the dual finite-diagram statement: every finite diagram \(\phi : J\to I\) has a cone, with arrows \(w_a : k\to\phi(a)\) satisfying \(\phi(\alpha)w_a=w_b\). In a partially ordered set, cofilteredness is the common-lower-bound condition. The empty category is neither filtered nor cofiltered.

2. Equality of elements has a common witness

Let \(I\) be small and filtered, and let \(D : I\to\mathsf{Set}_{\mathcal U}\). Smallness refers to the fixed working universe. The complete relabelling, tagged-union and quotient bounds are retained in Universes and small categories, Sections 2–4. They ensure that the following tagged union, and subsequently its quotient, are \(\mathcal U\)-small. If labels are not universe members, transport the resulting small set to an encoded representative.

Form \(T=\coprod_{i\in\operatorname{Ob}I}D(i)\). Write an element as \((i,x)\), retaining its stage \(i\). Define a relation by

\[ \begin{gathered} (i,x)\sim(j,y)\\ \Longleftrightarrow\\ \text{there exist }p : i\to k,\ q : j\to k\\ \text{with }D(p)(x)=D(q)(y). \end{gathered} \tag{2.1} \]

Proposition 2.1. This is an equivalence relation. The quotient \(Q=T/{\sim}\), with maps \(c_i : D(i)\to Q\) given by \(c_i(x)=[i,x]\), is a colimit of \(D\).

Proof of equivalence. Identities witness \((i,x)\sim(i,x)\). Interchanging the two witness arrows proves symmetry. For transitivity suppose \((i,x)\sim(j,y)\) has witnesses \(p_1 : i\to k\), \(p_2 : j\to k\), and \((j,y)\sim(r,z)\) has witnesses \(q_2 : j\to\ell\), \(q_3 : r\to\ell\). Choose a common target \(m\) and arrows \(a : k\to m\), \(b : \ell\to m\). The parallel arrows \(ap_2,bq_2 : j\to m\) can be equalized by an arrow \(h : m\to n\). Functoriality gives

\[ \begin{aligned} D(hap_1)(x)&=D(hap_2)(y),\\ &=D(hbq_2)(y),\\ &=D(hbq_3)(z). \end{aligned} \]

The middle equality uses \(hap_2=hbq_2\); the other two transport the original witness equalities. The arrows \(hap_1 : i\to n\) and \(hbq_3 : r\to n\) therefore witness \((i,x)\sim(r,z)\).

Proof of the universal property. For an arrow \(s : i\to j\), the arrows \(s\) and \(1_j\) witness \((i,x)\sim(j,D(s)(x))\). Hence \(c_jD(s)=c_i\), so the \(c_i\) form a cocone.

Now take any ambient set \(S\) and any cocone \(v_i : D(i)\to S\). If \(p,q\) witness \((i,x)\sim(j,y)\), then

\[ \begin{aligned} v_i(x)&=v_k(D(p)(x)),\\ &=v_k(D(q)(y)),\\ &=v_j(y). \end{aligned} \]

Thus the function on tagged elements descends to a well-defined function

\[ \begin{gathered} \bar v : Q\longrightarrow S,\\ \bar v([i,x])=v_i(x),\\ \bar v\circ c_i=v_i. \end{gathered} \tag{2.2} \]

Every class has a tagged representative, so a function with these composites must have this value on every class. This proves uniqueness. Conversely, any function \(a : Q\to S\) gives the cocone \((ac_i)_i\). These two constructions are inverse; postcomposing by any function \(S\to S'\) preserves their elementwise formulas. We have established the whole cocone-factor property, for all ambient targets and hence for the working-universe targets. \(\square\)

This quotient agrees with the general construction in Colimits as connected components, Section 1. Indeed our relation contains every generating pair \((i,x),(j,D(s)(x))\). Conversely, witnesses for (2.1) connect both elements to the single tagged element \((k,D(p)(x))\) by two generating steps. Since our relation is an equivalence relation, it is exactly the equivalence relation generated by these steps. Filteredness is what makes the common-witness test itself transitive.

For a natural transformation \(\theta:D\to D'\), the class formula \([i,x]\mapsto[i,\theta_i(x)]\) is well-defined. If \(p,q\) witness an equality, naturality transports it to \(D'(p)\theta_i(x)=D'(q)\theta_j(y)\). The formula preserves identities and composition pointwise and intertwines every structural map. Postcomposition of a target cocone gives the corresponding postcomposition of its unique quotient factor. Thus the quotient is the specified colimit functor as well as a colimit object.

If all the values \(D(i)\) are empty, then \(T\) and \(Q\) are empty despite \(I\) being nonempty. Formula (2.2) is still the unique empty function for every target. More generally, the proof makes no choice of an element from an empty class or an empty value.

Corollary 2.2 (a finite family at one stage). For a finite family \((\xi_t)_{t\in A}\) of elements of \(Q\), there are one object \(k\) and elements \(y_t\in D(k)\) with \(c_k(y_t)=\xi_t\) for every \(t\). In particular every finite subset of \(Q\) lies in the image of one \(c_k\).

Proof. Choose representatives \(\xi_t=[i_t,x_t]\). The finite-object part of Proposition 1.1 supplies a common target \(k\) and arrows \(p_t : i_t\to k\). Set \(y_t=D(p_t)(x_t)\). The cocone equations give \(c_k(y_t)=c_{i_t}(x_t)=\xi_t\). For an empty family, choose any object of \(I\); there are no elements to supply and no equations to check. This does not require \(D(k)\) to be nonempty. \(\square\)

Corollary 2.3 (one arrow for a same-stage equality). For \(x,y\in D(i)\), the following conditions are equivalent:

\[ \begin{gathered} c_i(x)=c_i(y);\\ \text{there exist }s : i\to j\\ \text{with }D(s)(x)=D(s)(y). \end{gathered} \tag{2.3} \]

Proof. Equality of the classes gives witnesses \(p,q : i\to k\) with \(D(p)(x)=D(q)(y)\). These may be different arrows. Choose \(h : k\to j\) with \(hp=hq\), and put \(s=hp=hq\). Then

\[ \begin{aligned} D(s)(x)&=D(h)(D(p)(x)),\\ &=D(h)(D(q)(y)),\\ &=D(s)(y). \end{aligned} \]

Conversely, equality after a single \(s\) implies equality in \(Q\) by the cocone equation \(c_jD(s)=c_i\). \(\square\)

A finite list of same-stage equations can be made true by one arrow. For pairs \(x_t,y_t\in D(i)\) with \(c_i(x_t)=c_i(y_t)\), choose witnesses \(s_t:i\to j_t\) from Corollary 2.3. A cocone on the finite graph of all these arrows gives \(s:i\to k\) and \(v_t:j_t\to k\) with \(v_ts_t=s\). Applying \(D(v_t)\) to each witness equation gives \(D(s)x_t=D(s)y_t\) simultaneously. For an empty list use \(1_i\). This synchronization includes the actual arrow composites.

Both corollaries can fail for a general index. On the discrete two-object category, take one singleton at each object. Its colimit has two elements, while each stage contributes only one; the two-element subset has no common stage. For a separate failure, take objects \(0,1\), two arrows \(a,b : 0\to1\), and only identity arrows besides these. Put \(D(0)=\{t\}\), \(D(1)=\{x,y\}\), with \(D(a)(t)=x\), \(D(b)(t)=y\). The general colimit identifies \(x\) and \(y\), but the only arrow leaving \(1\) is its identity, which does not make these distinct elements equal. This category does have common targets for pairs of objects; it lacks an arrow equalizing \(a,b\). The distinction between two witness arrows and a single eventual arrow is essential.

3. The underlying set of a module colimit

Let \(R\) be an associative unital ring, and use left \(R\)-modules. Neither commutativity of \(R\) nor injectivity of the transition maps is required. Suppose \(I\) is small and filtered and \(M:I\to\operatorname{Mod}(R)\). Apply Section 2 to the underlying sets, obtaining the small quotient set \(Q\) and maps \(c_i:M_i\to Q\).

Theorem 3.1. There is a unique module structure on \(Q\) for which all \(c_i\) are linear. With these maps, \(Q\) is the module colimit. Consequently the canonical map from the colimit of underlying sets to the underlying set of the module colimit is a natural bijection.

Proof. Write \([i,x]=c_i(x)\). For \(x\in M_i\), \(y\in M_j\), choose arrows \(a:i\to k\), \(b:j\to k\) and put

\[ \begin{gathered} {}[i,x]+[j,y]\\ =[k,M(a)x+M(b)y],\\ r[i,x]=[i,rx],\\ -[i,x]=[i,-x]. \end{gathered} \tag{3.1} \]

Define \(0_Q=[i,0]\) at any object \(i\). Nonemptiness supplies such an object, and a common target shows that this definition does not depend on it.

Here are the representative checks for addition. First keep \(i,x,j,y\) fixed and compare two chosen targets \(k,k'\) and their two pairs of arrows. Apply the finite graph cocone construction to the objects \(i,j,k,k'\) and these four arrows. At its target, the two transported copies of \(x\) agree, as do the two copies of \(y\). Linearity of the transitions therefore makes the two sums agree there, so they define the same element of \(Q\).

Next replace \([i,x]\) by an equal representative \([i',x']\). Section 2 supplies arrows to a common object at which their values agree. Include this witness, the chosen addition arrows, and the representative of the second summand in one finite graph. Its cocone makes both first summands equal and transports the second summand identically. Again the two sums agree at its target. Replacing the second summand is proved by the same argument with its own equality witness. Thus addition is independent of both representatives and of the chosen common target. If \([i,x]=[i',x']\), an equality witness remains an equality after multiplying by \(r\) or taking negatives, since every transition is linear. This proves that the other two operations are well-defined.

All module laws can be checked at a common stage. For associativity, choose a common stage for three representatives and use independence of the chosen addition targets to compute both parenthesizations there. The stage module's associative law proves equality. The same two-representative argument proves commutativity and scalar distributivity over addition. Zero and additive inverses are checked with a single representative. At that same stage, the laws

\[ \begin{aligned} (r+s)[i,x]&=r[i,x]+s[i,x],\\ (rs)[i,x]&=r\bigl(s[i,x]\bigr),\\ 1[i,x]&=[i,x] \end{aligned} \tag{3.2} \]

follow from the corresponding left-module laws in \(M_i\). The order \(rs\) in the second line is unchanged. This establishes every module axiom.

Computing addition at stage \(i\) shows that \(c_i\) is additive, and the scalar formula makes it \(R\)-linear. Conversely any module structure making all \(c_i\) linear must have (3.1): move two representatives to a common target and use that target's linear \(c_k\). Each element has a representative, so this also proves uniqueness of the structure.

For any module \(N\) and compatible linear maps \(v_i:M_i\to N\), the full Set colimit factor from Section 2 is the unique function

\[ \begin{gathered} \bar v:Q\longrightarrow N,\\ \bar v([i,x])=v_i(x). \end{gathered} \tag{3.3} \]

The definition of addition and compatibility give \(\bar v([i,x]+[j,y])=v_i(x)+v_j(y)\); the scalar formula gives \(\bar v(r[i,x])=r v_i(x)\). Thus the factor is linear. Every linear factor is a Set factor and hence is this one. This proves the colimit universal property for every module target, including the zero module, without a choice of lifts for a whole target family.

Let \(L\) be any other specified module colimit with maps \(\ell_i\). The two colimit properties give unique linear maps \(Q\to L\) and \(L\to Q\) preserving all structural maps. Their composites preserve those maps as well and so are the respective identities. The underlying map \(Q\to L\) is the canonical Set comparison, because its value on \([i,x]\) is \(\ell_i(x)\). Hence it is a bijection.

For a natural transformation \(M\to M'\), the induced map is \([i,x]\mapsto[i,\theta_i(x)]\). The same common-stage formulas prove it linear. The two comparisons to specified colimits commute with it, since they do so on every representative. This proves the stated naturality. \(\square\)

An underlying module always contains zero, so \(Q\) is nonempty for filtered \(I\), even when every \(M_i\) is the zero module. The zero diagram has a singleton underlying Set colimit and a zero module colimit, as the theorem requires. The empty index is not filtered: its Set colimit is empty and its module colimit is the zero module with one underlying element.

There is a second useful proof of the comparison, using the complete module colimit construction. That construction takes a direct sum and divides by arrow relations. The finite-relation proof proves that every class is represented at one stage, and that two representatives are equal exactly when their images agree at a common target. These are precisely the quotient and equality test of Section 2. Both identifications send a representative to its specified structural image. The direct construction above additionally supplies the complete Set-based operations and all-target factor for the forgetful comparison.

Example. A nonfiltered index can lose this comparison even for a finite module. Regard the group \(C_2\) as a one-object category. On \(M=\mathbb F_2^2\), let its nonidentity arrow interchange the basis vectors \(e_1,e_2\). The underlying Set colimit is the orbit set with three classes: \(\{0\}\), \(\{e_1,e_2\}\), and \(\{e_1+e_2\}\). Every invariant function has exactly one value on each orbit, which proves this Set colimit's full factor property.

An invariant linear map \(v:M\to N\) satisfies \(v(e_1)=v(e_2)\), equivalently \(v(e_1+e_2)=0\). It therefore factors uniquely through the module quotient by the line spanned by \(e_1+e_2\), and each linear map out of that quotient is invariant. This is the module colimit, with two elements. The canonical Set comparison sends both the zero orbit and the \(e_1+e_2\) orbit to its zero coset, so is not injective. Addition directly explains the obstruction: the orbit of \(e_1\) added to itself would give the zero orbit using representatives \(e_1,e_1\), but the different \(e_1+e_2\) orbit using \(e_1,e_2\). The filtered refinement step in the proof is essential.

4. Finite limits detect filteredness

Work in \(\mathsf{Set}_{\mathcal U}\), with the size convention of Universes and small categories, Sections 2–5. A small category has both a small object set and small Hom sets. Its arrow set is small by the transported tagged-union bound. Thus every colimit below has a small tagged union and quotient, and every finite limit has small products and an equalizer subset. The functor category may have its objects in a larger ambient universe; that does not enlarge the value sets. A finite category has finitely many objects and arrows, and may be empty.

Theorem 4.1. For a small category \(I\), the following are equivalent:

  1. \(I\) is filtered.
  2. The functor \(\operatorname{colim}_I\colon \operatorname{Fun}(I,\mathsf{Set}_{\mathcal U})\to\mathsf{Set}_{\mathcal U}\) preserves every finite limit.

Equivalently, for every finite \(J\) and every \(D\colon I\times J^{\mathrm{op}}\to\mathsf{Set}_{\mathcal U}\), the specified comparison is bijective:

\[ \begin{gathered} \Gamma_D\colon \operatorname{colim}_{i\in I}L_i\\ \longrightarrow\lim_{j\in J^{\mathrm{op}}}Q_j,\\ L_i=\lim_{j\in J^{\mathrm{op}}}D(i,j),\\ Q_j=\operatorname{colim}_{i\in I}D(i,j),\\ \Gamma_D([i,(x_j)_j])=([i,x_j])_j. \end{gathered} \tag{4.1} \]

Here and below \([i,x]\) retains its index tag. An arrow \(s\colon i\to i'\) acts on \(L_i\) coordinatewise by \(D(s,j)\). For \(a\colon j\to j'\) in \(J\), the map \(Q(a)\colon Q_{j'}\to Q_j\) sends \([i,x]\) to \([i,D(i,a)x]\). The two-variable functor law makes both definitions preserve their respective compatibility equations and generating class relations. It follows that (4.1) lands in the indicated limit and respects every colimit generator. It is the actual cone-induced comparison.

The \(I\)-diagram \(L\) is the limit of the finite diagram of \(I\)-diagrams, with its natural coordinate projections. Indeed, a cone with vertex \(F\colon I\to\mathsf{Set}_{\mathcal U}\) factors uniquely at each \(i\) through the compatible-tuple set \(L_i\). For \(s\colon i\to i'\), the two candidate composites into \(L_{i'}\) have equal coordinate projections by the cone transformations' naturality. Tuple uniqueness makes them equal, proving the factor natural in \(I\). Componentwise uniqueness then proves its uniqueness as a transformation. Thus (4.1) is exactly the comparison used in finite-limit preservation in the functor category.

Proof, forward direction. Assume \(I\) filtered. We use the full finite-cocone criterion of Section 1 and the common-stage equality criterion of Section 2. In particular, finitely many arrows and objects can be placed in one commuting cocone; merely finding a common target need not make their composites agree.

Finite products, including no factors. Let \(K\) be a finite set and \(A^k\colon I\to\mathsf{Set}_{\mathcal U}\) for \(k\in K\). The comparison is

\[ \begin{gathered} P\colon \operatorname{colim}_i\prod_{k\in K}A^k(i)\\ \longrightarrow\prod_{k\in K}\operatorname{colim}_iA^k(i),\\ P([i,(x_k)_k])=([i,x_k])_k. \end{gathered} \tag{4.2} \]

For surjectivity with \(K\ne\varnothing\), start with a tuple of classes and choose a representative \((i_k,x_k)\) for each coordinate. There are only finitely many choices. A cocone on the discrete family \((i_k)_k\) gives \(i\) and arrows \(s_k\colon i_k\to i\). The tuple \((A^k(s_k)x_k)_k\) at \(i\) maps to the desired tuple of classes. This argument does not assume nonempty value sets: it begins with a tuple on the right. If the right side is empty, surjectivity is vacuous; the existence of \(P\) then forces its domain empty as well.

For injectivity, suppose representatives \((i,(x_k)_k)\) and \((i',(y_k)_k)\) have the same image. For each \(k\), the common-stage criterion supplies

\[ \begin{gathered} u_k\colon i\to\ell_k,\qquad v_k\colon i'\to\ell_k,\\ A^k(u_k)x_k=A^k(v_k)y_k. \end{gathered} \tag{4.3} \]

Use a finite abstract diagram with two source objects, one sink for each \(k\), and the arrows \(u_k,v_k\); separate labels are allowed even when their images in \(I\) coincide. There are no nonidentity composites in this abstract shape. A cocone gives \(a\colon i\to n\), \(b\colon i'\to n\) and \(w_k\colon \ell_k\to n\) such that \(w_ku_k=a\) and \(w_kv_k=b\) simultaneously. Applying \(A^k(w_k)\) to (4.3) gives \(A^k(a)x_k=A^k(b)y_k\) for every coordinate. The two product tuples therefore have equal images at \(n\), so their product-colimit classes agree. Synchronizing both families of composites is essential for a category with parallel arrows.

If \(K=\varnothing\), each product is a singleton. Filteredness gives an object of \(I\), and any two objects have a common target. Consequently all classes \([i,*]\) are equal and one exists. Thus (4.2) is the unique bijection between singletons. In contrast, for empty \(I\) this comparison would be \(\varnothing\to\{*\}\), so preservation of the zero-factor product includes nonemptiness.

Equalizers. Let \(f,g\colon A\rightrightarrows B\) be natural transformations of \(I\)-diagrams. Set \(E(i)=\{x\in A(i)\colon f_i(x)=g_i(x)\}\). Naturality makes \(A(s)\) restrict to \(E(s)\), and the comparison is

\[ \begin{gathered} \Lambda\colon \operatorname{colim}_iE(i)\longrightarrow Z,\\ Z=\operatorname{Eq}(\operatorname{colim}f, \operatorname{colim}g),\\ \Lambda([i,x])=[i,x]. \end{gathered} \tag{4.4} \]

For surjectivity, take \([i,x]\in Z\). The elements \(f_i(x),g_i(x)\) have equal classes in the colimit of \(B\). The common-stage criterion gives \(u,v\colon i\to\ell\) with \(B(u)f_i(x)=B(v)g_i(x)\). Coequalize the parallel arrows: choose \(t\colon \ell\to n\) with \(tu=tv=s\). Then \(B(s)f_i(x)=B(s)g_i(x)\). Naturality gives \(f_n(A(s)x)=g_n(A(s)x)\), so \(A(s)x\in E(n)\), and its class maps to \([i,x]\).

For injectivity, take \(x\in E(i)\) and \(y\in E(i')\) whose images in the colimit of \(A\) agree. There are \(a\colon i\to n\) and \(b\colon i'\to n\) with \(A(a)x=A(b)y\). These are exactly \(E(a)x\) and \(E(b)y\), since each already lies in \(E(n)\). Their equality gives the same colimit class in \(E\). This proves both directions, including empty equalizer values.

The product and equalizer comparisons commute with transformations: applying a component map before taking a class has the same value as applying its induced class map afterward. For equalizers this means a commuting map of parallel-pair diagrams. Their inverses are independent of every choice of representatives, cocones and witnesses, by the injectivity just proved.

Every finite shape. Fix the finite \(J\) and \(D\) of (4.1). For each \(i\), form

\[ \begin{gathered} V_i=\prod_{j\in\operatorname{Ob}J}D(i,j),\\ W_i=\prod_{a\colon j\to j'}D(i,j),\\ r_i,t_i\colon V_i\rightrightarrows W_i,\\ (r_i x)_a=x_j,\\ (t_i x)_a=D(i,a)x_{j'},\\ L_i=\operatorname{Eq}(r_i,t_i). \end{gathered} \tag{4.5} \]

Both products are finite because the object and arrow sets are finite. These equalizer equations are precisely the \(J^{\mathrm{op}}\)-cone equations. The complete factor proof in Universal forks, Section 8 says that this equalizer, with its coordinate projections, is the limit: a cone gives a unique tuple map, its equations equalize \(r_i,t_i\), and the equalizer gives the unique factor. This includes empty \(J\), when both products and the equalizer are singletons.

The two-variable laws make \(V,W\) into \(I\)-diagrams and \(r,t\) into transformations. Apply the proved equalizer comparison to them. Apply the product comparisons to identify \(\operatorname{colim}V\) with \(\prod_jQ_j\) and \(\operatorname{colim}W\) with \(\prod_{a\colon j\to j'}Q_j\). Under these identifications, \(\operatorname{colim}r\) has coordinate \(z_j\), while \(\operatorname{colim}t\) has coordinate \(Q(a)z_{j'}\): this follows directly by evaluating on \([i,(x_j)_j]\). Their equalizer is therefore \(\lim_{J^{\mathrm{op}}}Q\), by the same complete factor proof. The resulting bijection is exactly \(\Gamma_D\), since each of its coordinates is \([i,x_j]\).

One can read its inverse concretely. Given a compatible family of classes, use the product-surjectivity construction to represent all its coordinates by \((x_j)_j\) at one \(i\). For each arrow \(a\colon j\to j'\), compatibility says that \(x_j\) and \(D(i,a)x_{j'}\) have the same class. The equalizer-surjectivity argument gives a single arrow \(s_a\colon i\to n_a\) making that equation true. A cocone on the finite star of all the \(s_a\) supplies \(s\colon i\to n\) and \(w_a\colon n_a\to n\) with \(w_as_a=s\). At \(n\), the tuple \((D(s,j)x_j)_j\) satisfies every equation and thus belongs to \(L_n\). Its class is the inverse image. Injectivity of \(\Gamma_D\), already obtained from the equalizer and product comparisons, proves that all choices give that same class. If \(J\) is empty, choose any \(i\), using filtered nonemptiness; the empty tuple represents the unique inverse image.

For a transformation \(\theta\colon D\to D'\), naturality is the explicit equation

\[ \begin{gathered} \Gamma_{D'}\,(\operatorname{colim}_i\lim_j\theta)\\ =(\lim_j\operatorname{colim}_i\theta)\,\Gamma_D,\\ \Gamma_{D'}^{-1}\,(\lim_j\operatorname{colim}_i\theta)\\ =(\operatorname{colim}_i\lim_j\theta)\,\Gamma_D^{-1}. \end{gathered} \tag{4.6} \]

The first equation holds on representatives, with both routes giving \(([i,\theta_{i,j}x_j])_j\); the second follows by composing with the proved inverses. Restricting along a functor between finite index categories also commutes with the comparison: both routes retain the same selected coordinates. The inverse commutes as well by uniqueness. Hence this is a natural isomorphism of the specified limit-colimit constructions, and proves preservation of all finite limits in the functor category.

Proof, converse direction. Assume preservation of all finite limits. For a finite \(J\) and a functor \(\phi\colon J\to I\), define

\[ \begin{gathered} H(i,j)=\operatorname{Hom}_I(\phi(j),i),\\ H(s,a)(h)=s\,h\,\phi(a)\\ s\colon i\to i',\qquad a\colon j\to j',\\ h\colon \phi(j')\to i. \end{gathered} \tag{4.7} \]

This is covariant in \(I\) and contravariant in \(J\). Postcomposition and precomposition commute by associativity; identities and composites follow from the functor laws of \(\phi\) and the category laws of \(I\). Small Hom sets make these permitted small-set values.

For any fixed \(j\), every element \(h\colon \phi(j)\to i\) is the image of \(1_{\phi(j)}\) under postcomposition by \(h\). The full class-colimit construction in Colimits as connected components, Section 3 therefore gives

\[ [i,h]=[\phi(j),1_{\phi(j)}]. \tag{4.8} \]

Every class has a representative and the identity class exists. Thus the unique map \(\operatorname{colim}_iH(i,j)\to\{*\}\) is bijective, with inverse the displayed identity class. No filteredness is used in this argument, and individual Hom values may be empty. These bijections are natural in \(j\), because every function between singleton sets is the unique such function. Their diagram is consequently the constant singleton diagram. Its limit is a singleton for every \(J\), including empty \(J\).

Preservation applied to \(H\) now makes \(\operatorname{colim}_i\lim_jH(i,j)\) a singleton. In the tagged-union quotient describing this colimit, a class must be represented by some \(i\) and some element of \(\lim_jH(i,j)\). Such an element is precisely a family \(h_j\colon \phi(j)\to i\) satisfying \(h_j=h_{j'}\phi(a)\) for every \(a\colon j\to j'\): it is a cocone on \(\phi\).

For empty \(J\), each \(\lim_jH(i,j)\) is a singleton, so this same argument forces \(I\) to have an object. In particular empty \(I\) cannot satisfy preservation. For every finite \(J\) we have obtained an actual cocone, with all its equations. The finite-cocone criterion in Section 1 proves that \(I\) is filtered. This completes both directions of Theorem 4.1. \(\square\)

5. Four graded exercises with full solutions

Exercise 1 — introductory: repair a finite triangle

In a filtered category, suppose \(f,g : A\to B\), \(h : B\to C\), and \(u : A\to C\) satisfy \(hf=hg=u\). Consider the finite diagram consisting of these three objects and arrows, with those composition relations. Choose any common target \(T\) and arrows \(r_A : A\to T\), \(r_B : B\to T\), \(r_C : C\to T\). Construct a cocone by at most three successive applications of the parallel-arrow condition. Explain why the equation involving \(u\) needs no additional application.

Solution. A common target for the three objects exists by two applications of the common-target condition. Equalize \(r_A\) and \(r_Bf\) by \(e_1 : T\to T_1\), and set \((A_1,B_1,C_1)=(e_1r_A,e_1r_B,e_1r_C)\); these symbols denote arrows from \(A,B,C\), not objects. Then \(B_1f=A_1\).

Equalize \(A_1\) and \(B_1g\) by \(e_2 : T_1\to T_2\), and postcompose all three arrows to obtain \(A_2,B_2,C_2\). We have \(B_2f=A_2\) because the first equation survives postcomposition, and \(B_2g=A_2\) by the new equalization. Finally equalize \(B_2\) and \(C_2h\) by \(e_3 : T_2\to T_3\), and postcompose to obtain \(A_3,B_3,C_3\). The resulting equations are

\[ \begin{aligned} B_3f&=A_3,\\ B_3g&=A_3,\\ C_3h&=B_3. \end{aligned} \tag{5.1} \]

The remaining arrow equation follows from the specified composition relation:

\[ \begin{aligned} C_3u&=C_3hf,\\ &=B_3f,\\ &=A_3. \end{aligned} \tag{5.2} \]

These are all nonidentity-arrow equations, and the identity equations are automatic. Thus the three arrows to \(T_3\) form a cocone. Each equalizer step applies to parallel arrows with the displayed common domain and codomain; postcomposition preserves the equations already established. If a pair already agrees, its target identity can serve as that step.

Exercise 2 — intermediate: locate two different failures

First use a discrete two-object category and a singleton at each object. Compute its colimit and find a finite subset which cannot be represented at one stage. Then use the parallel-arrow diagram described at the end of Section 2. Compute its colimit, show that its common-witness relation (2.1) is not transitive, and exhibit an equality of two elements at one stage which cannot hold after any single outgoing arrow. State which filteredness axiom fails in each index.

Solution. Write the discrete objects as \(U,V\) and the respective singleton elements as \(a,b\). There are no generating identifications between the two tags. The quotient is

\[ \begin{gathered} Q=\{[U,a],[V,b]\},\\ c_U(D(U))=\{[U,a]\},\\ c_V(D(V))=\{[V,b]\}. \end{gathered} \tag{5.3} \]

Every pair of functions from the singleton values to a target \(S\) is a cocone, since no nonidentity-arrow equation is imposed. There is exactly one function from this two-element set to \(S\) with those two values, confirming the colimit property, including when no such functions exist. The finite subset \(Q\) itself is contained in neither stage image. The index is nonempty and its only parallel-arrow pairs are equal, so the failing axiom is the common-target condition for \(U,V\).

For the second diagram, the generating identifications join \((0,t)\) to both \((1,x)\) and \((1,y)\). These are the only three tagged elements, so its quotient is a singleton. Equivalently, a cocone \(v_0,v_1\) into any set \(S\) must satisfy \(v_1(x)=v_0(t)=v_1(y)\), and a function from a singleton to \(S\) is uniquely specified by this common value. This proves the asserted colimit for every target.

For the common-witness test, \((1,x)\sim(0,t)\) is witnessed by \(1_1,a\), and \((0,t)\sim(1,y)\) by \(b,1_1\). But a common target of two copies of \(1\) can only be \(1\), and both witness arrows must be \(1_1\). As \(x\ne y\), these cannot witness \((1,x)\sim(1,y)\). Thus this relation is not transitive. In the colimit we nevertheless have

\[ \begin{gathered} c_1(x)=c_1(y),\\ D(1_1)(x)=x\ne y=D(1_1)(y). \end{gathered} \tag{5.4} \]

There is no other outgoing arrow from \(1\), so no single arrow can realize that equality. Every pair of objects has common target \(1\), and the index is nonempty. Its failure is precisely the parallel-arrow condition: the only possible postcomposition of \(a,b\) is by \(1_1\), and \(a\ne b\). The generated equivalence relation always gives the colimit; the simpler common-witness test and its single-arrow consequence require filteredness.

Exercise 3 — advanced: two failures in one connected category

Let \(I\) have one object and arrow group \(C_2=\{1,\sigma\}\), with \(\sigma^2=1\). Let \(A=\{0,1\}\), on which \(\sigma\) exchanges the two elements. Compute the product comparison for \(A\times A\), and the equalizer comparison for the equivariant maps \(f=1_A\) and \(g=\sigma\colon A\to A\). Show that this connected category is not filtered, despite preserving the terminal object under colimits.

Solution. A set diagram on this category is a \(C_2\)-set, and the class relation identifies each element with its translate; hence its colimit is its orbit set. The action on \(A\) is transitive, so \(\operatorname{colim}A\) is a singleton. On \(A\times A\), the diagonal action has exactly two orbits:

\[ \begin{gathered} \{(0,0),(1,1)\},\\ \{(0,1),(1,0)\},\\ \operatorname{colim}(A\times A)\\ \longrightarrow(\operatorname{colim}A)^2,\\ \text{the comparison }2\to1. \end{gathered} \tag{5.5} \]

Thus the product comparison identifies two different classes and is not injective. The two maps \(1_A\) and \(\sigma\) commute with the action and are transformations. Their pointwise equalizer is empty since the exchange has no fixed element. On the singleton orbit set their induced maps coincide. Consequently

\[ \begin{gathered} \operatorname{colim}\operatorname{Eq}(1_A,\sigma) =\varnothing,\\ \operatorname{Eq}(\operatorname{colim}1_A, \operatorname{colim}\sigma)\\ =\{*\}. \end{gathered} \tag{5.6} \]

The equalizer comparison is not surjective. No arrow \(s\) can coequalize the parallel arrows \(1,\sigma\): the equation \(s=s\sigma\), after multiplying by \(s^{-1}\), would give \(1=\sigma\). Thus the filtered parallel-arrow axiom fails. The category has one object, so it is nonempty and connected, and its constant singleton diagram has singleton colimit. Preserving only the terminal object does not repair either failure.

Exercise 4 — challenge: equations that become true later

Take \(I=\mathbb N\) with its usual order as a category. Put \(A_n=\{0,\ldots,n\}\), \(B_n=\{0,1\}\), and \(T_n=\{0,\ldots,2n\}\). The \(A\)- and \(T\)-transitions are inclusions; every strict \(B\)-transition is the constant function with value \(0\). Define \(f_n\colon A_n\to B_n\) to be constantly \(0\), and define \(g_n(x)=1\) for \(x=n\), with \(g_n(x)=0\) for \(x<n\). Verify the diagrams and transformations, then compute the comparison for the finite limit \(L_n=\operatorname{Eq}(f_n,g_n)\times T_n\). Also compute the comparison for an empty finite shape, and explain what happens if the index \(I\) itself is empty.

Solution. The strict \(B\)-transition functions compose to the same constant function, and identity transitions are identities, so \(B\) is a functor. If \(m>n\), every \(x\in A_n\) has \(x<m\). Thus \(g_m(x)=0\), which is also the image of \(g_n(x)\) under the strict \(B\)-transition. The same statement holds for \(f\), proving both naturality equations; identity arrows give them trivially. The order category is filtered: it is nonempty, finitely many numbers have a common upper bound, and two parallel arrows always coincide.

The equalizer is \(E_n=\{0,\ldots,n-1\}\), with \(E_0=\varnothing\), and its transitions are inclusions. Each \(x\in\mathbb N\) enters \(E\) at stage \(x+1\). All elements of \(B\) have the same colimit class, since at the next stage both are sent to \(0\). Therefore \(\operatorname{colim}A=\mathbb N\), \(\operatorname{colim}B=\{*\}\) and \(\operatorname{colim}T=\mathbb N\), with the two induced maps from \(A\) equal. The right-hand finite limit is \(\mathbb N\times\mathbb N\). The actual comparison is

\[ \begin{gathered} \operatorname{colim}_n(E_n\times T_n)\\ \xrightarrow{\ \sim\ }\mathbb N\times\mathbb N,\\ [n,(x,y)]\longmapsto(x,y),\\ (x,y)\longmapsto[n,(x,y)],\\ n\ge\max\{x+1,\lceil y/2\rceil\}. \end{gathered} \tag{5.7} \]

Such an \(n\) always exists. Two choices of \(n\) give the same class at their maximum, proving the inverse independent of the choice. Conversely, two representatives with the same pair become identical at the maximum of their stages, proving injectivity; the displayed choice proves surjectivity. Stage \(0\) contributes nothing to this colimit because its equalizer is empty, although the final colimit is nonempty. This limit is an actual finite-category limit: take the parallel-pair shape for \(f,g\) and an isolated object for \(T\).

For an empty finite shape, the stage limit is the singleton of the empty tuple. All its stage classes agree and one exists, giving

\[ \begin{gathered} \operatorname{colim}_{n\in\mathbb N}\{()\} \xrightarrow{\ \sim\ }\{()\},\\ \operatorname{colim}_{i\in\varnothing}\{()\} =\varnothing\longrightarrow\{()\}. \end{gathered} \tag{5.8} \]

The second comparison is not bijective. An empty finite limit is required even when a finite shape has no objects; an empty colimit index violates precisely this requirement and the nonemptiness axiom of filteredness.
