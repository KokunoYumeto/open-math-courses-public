Number theory

Class field theory

Reciprocity for local and global fields, built from Galois theory, cyclic cohomology and radicals, then made explicit with Lubin–Tate groups, idèles and ray class fields.

Take first

Begin with finite Galois theory and basic topology. Number fields, local fields and analytic number theory supply the arithmetic prerequisites for later lessons. Each lesson identifies the particular results it uses.
