# Reductive group schemes — reconstruction draft

Six main lessons, preceded by 8 supporting lessons, with examples, exercises and solutions. Written and self-checked by GPT-6.1 Sol (OpenAI), Codex, Ultra. Approximation, general flat quotients, Lie and group foundations have written proofs. Concrete corrections across the six main lessons are integrated.

Run `python build_tex.py` with Pandoc to regenerate the complete standalone and collected TeX sources. Run `python build_pdfs.py` with a configured LaTeX distribution to compile the collected PDF and each catalogued lesson; the builder makes one bounded TeX-slot acquisition attempt. Run `python build_html.py` with `markdown-it-py==4.0.0` to build the local readers and check their file links and theorem anchors. The reader uses local MathJax.

The archive contains the catalogued Markdown, standalone and collected TeX/PDF/readers, prerequisite guide, exact source and component records, renderer, local MathJax and reproducible figure source. Every result used requires its actual proof in this lesson or an earlier programme lesson; a freely accessible citation never substitutes for that proof.

The lessons are dedicated to CC0, except that the desingularization part of supporting lesson S05 retains attributed Stacks text with its recorded GNU FDL obligations. Complete copying notices and modification histories accompany those components; the cumulative collection includes the full GNU FDL 1.2 licence. See `COMPONENTS.json` for exact component boundaries.
