# Reductive group schemes

Six main lessons and eight supporting lessons on tori, centralizers, roots, root data, integral pinned groups, forms and flag schemes. The edition includes worked examples, exercises followed by their solutions, individual readers and PDFs, a collected PDF, and editable Markdown and LaTeX sources.

Build the TeX with `python build_tex.py`, the readers with `python build_html.py`, and the PDFs with `python build_pdfs.py`. Pandoc, markdown-it-py and a LaTeX distribution are required. Source figures and local mathematical rendering assets accompany the edition.
